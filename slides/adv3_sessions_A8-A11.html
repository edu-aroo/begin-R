A9 — PDF et publication

Typst ou LaTeX ?

  • Typst : rien à installer, très rapide → rapports courants (citeproc: true)
  • LaTeX : quarto install tinytex → listes des figures/tableaux, modèles officiels
  • mise en page : papersize: a4, margin: / geometry:, fontsize:, {{< pagebreak >}}
  • Word : reference-doc: styles.docx (modifier les styles)
  • un seul HTML à envoyer : embed-resources: true
