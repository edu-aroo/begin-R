Le contexte

Une coopérative d’algoculture (12 villages, 96 cultivateurs) note ses cordes dans un classeur Excel ; une ONG mesure l’eau à 10 stations ; une enquête ménages (420 ménages) décrit les activités et revenus. Tout est simulé : aucun lieu réel.

Saisons et taux de croissance

lines$season <- ifelse(month(lines$planting_date) %in% c(11:12, 1:4), "wet", "dry")
i <- which(lines$final_weight_kg > 200)        # poids saisis en grammes
lines$final_weight_kg[i] <- lines$final_weight_kg[i] / 1000
lines$sgr <- 100 * log(lines$final_weight_kg / lines$initial_weight_kg) / lines$days

I2 — Restructurer

Large ou long ?

wide <- read.csv("data/water_quality_wide.csv", check.names = FALSE)
wide[1:3, 1:6]
#>   station 2023-01 2023-02 2023-03 2023-04 2023-05

  • large : lisible pour un humain, une colonne par mois
  • long (« rangé ») : une variable par colonne, une observation par ligne → ce que veulent dplyr et ggplot

I3 — Joindre

Une clé commune

seaweed <- lines %>%
  left_join(farmers, by = "farmer_id") %>%                     # qui cultive ?
  left_join(read.csv("data/villages.csv")[, c("village", "zone")], by = "village")
c(avant = nrow(lines), apres = nrow(seaweed))                  # doit être identique !
#> avant apres 
#>  2575  2575
Si le nombre de lignes augmente après left_join(), la clé n’est pas unique dans la table de référence : sum(duplicated(farmers$farmer_id)).

Les familles de jointures

dplyr Garde R de base
left_join(x, y) toutes les lignes de x merge(x, y, all.x = TRUE)
inner_join(x, y) lignes présentes dans les deux merge(x, y)
full_join(x, y) tout merge(x, y, all = TRUE)
anti_join(x, y) lignes de x sans correspondance x[!x$k %in% y$k, ]

anti_join() pour trouver les erreurs

hh  <- read.csv("data/survey_households.csv", na.strings = "")
mem <- read.csv("data/survey_members.csv")

I4 — Données d’enquête

Doublons et textes libres

sum(duplicated(hh))                        # lignes saisies deux fois

hh <- hh[!duplicated(hh), ]
table(hh$mpa_benefits)[1:6]                # « Agree », « agree », « AGREE ».
#> 
#>              Agree     Strongly agree  Strongly disagree              agree 
#>                  5                  4                  1                  9 
#>              Agree           Disagree 
#>                136                 46
hh$mpa_benefits <- str_to_sentence(str_squish(hh$mpa_benefits))

Échelle de Likert = facteur ordonné

lik <- c("Strongly disagree", "Disagree", "Neutral", "Agree", "Strongly agree")
hh$mpa_benefits <- factor(hh$mpa_benefits, levels = lik, ordered = TRUE)
round(prop.table(table(hh$mpa_benefits)) * 100, 1)
#> 
#> Strongly disagree          Disagree           Neutral             Agree 
#>               7.3              11.2              26.0              36.4 
#>    Strongly agree
