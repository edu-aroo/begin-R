Mesurer et combiner

zones$km2 <- as.numeric(st_area(zones)) / 1e6
tapply(zones$km2, zones$zone, sum) |> round(1)
#> Fishing No-take 
#>   441.4   294.3
belt <- st_buffer(st_union(filter(zones, zone == "No-take")), 2000)     # 2 km
villages$village[lengths(st_intersects(villages, belt)) > 0]
#> [1] "Antsiraka"  "Ampasimena" "Befasy"     "Andrevobe"  "Tsimanjaka"

A6 — terra

Un raster : une grille de valeurs

bathy <- rast("data/advanced/bathymetry.tif"); sst <- rast("data/advanced/sst_2024.tif")
c(res = res(bathy)[1], cellules = ncell(bathy), couches_sst = nlyr(sst))
#>         res    cellules couches_sst 
#>     2.5e-03     7.2e+04     1.2e+01
  • étendue, résolution, SCR, couches, NA
  • crop(), mask(), project() (bilinear / near), classify()
  • algèbre cellule par cellule : max(sst), sum(sst > 29.5)

Extraire aux sites → relier au terrain

sv <- vect(st_transform(sites, crs(sst)))
heat <- data.frame(site_id = sites$site_id, zone = sites$zone, sst_max = extract(max(sst), sv)[, 2]) |>
  left_join(reef |> filter(year == 2024) |> group_by(site_id) |> summarise(bl = mean(bleached_pct)), by = "site_id")
ggplot(heat, aes(sst_max, bl, colour = zone)) + geom_point(size = 3) +
  labs(x = "SST max 2024 (°C)", y = "Blanchies 2024 (%)", colour = NULL) + theme_minimal()

r = 0.65 : un indice, pas une preuve (18 sites, grille de 2 km).

A7 — Cartes

geom_sf + coord_sf

ggplot() + geom_sf(data = land, fill = "#efe6d2") +
  geom_sf(data = zones, aes(fill = zone), alpha = .6) + geom_sf(data = sites, size = 1) +
  scale_fill_manual(values = c("No-take" = "#1b7f8c", "Fishing" = "#f2b8a2"), name = NULL) +
  coord_sf(xlim = bb[c(1, 3)], ylim = bb[c(2, 4)], datum = 4326) +
  scale_x_continuous(breaks = c(43.4, 43.6)) + theme_minimal()

Règles d’une bonne carte

  • quoi, où, quand dans le titre ou la légende
  • légende avec unités ; source et SCR en bas
  • barre d’échelle en SCR projeté + flèche du nord
  • palette séquentielle (quantité), divergente (variation autour de 0), qualitative (catégories)
  • 5 à 7 classes au maximum ; fond discret

Rasters et tmap

  • ggplot2 : as.data.frame(r, xy = TRUE) + geom_raster() (ou tidyterra)
  • petits multiples : facet_wrap(~ year)
  • tmap 4 : tm_shape() + tm_polygons(fill = ...) + tm_dots() + tm_scalebar() + tm_compass()
  • tmap_mode("view") → carte interactive avec le même code
