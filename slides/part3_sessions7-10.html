Séance 7 — Graphiques avec R de base

Quel graphique pour quelle question ?

Question Graphique Fonction
Distribution d’une variable ? histogramme hist()
Deux variables liées ? nuage de points plot(x, y)
Différences entre groupes ? boxplot boxplot(y ~ g)
Comparer des moyennes ? barres + barres d’erreur barplot() + arrows()
Effectifs par catégorie ? barres barplot(table(x))

Séance 8 — Packages, dplyr et ggplot2

Qu’est-ce qu’un package ?

Installer une fois, charger à chaque fois

  • R de base = déjà des packages : base, stats, graphics, utils, tools…
  • CRAN : plus de 20 000 packages (vegan, sf, lme4…)
  • tidyverse : dplyr (données), ggplot2 (graphiques), tidyr, readr…
install.packages(c("dplyr", "ggplot2"))   # UNE FOIS, dans la console
library(dplyr)                            # EN HAUT DE CHAQUE SCRIPT
library(ggplot2)
dplyr::filter(sg, seagrass_cover > 80)    # :: sans charger

« masked » au chargement : normal (ex. filter de stats). « there is no package » : pas encore installé.

ggplot2 : la grammaire des graphiques

  1. ggplot(données, aes(x = ..., y = ..., colour = ...)) — données + esthétique
  2. + geom_*() — la forme : geom_point(), geom_boxplot(), geom_col(), geom_errorbar()…
  3. + labs(), + theme_*(), + scale_*(), + facet_wrap()

R de base : on trace, puis on ajoute (points(), arrows(), legend()). ggplot2 : on empile des couches avec +. Même logique, syntaxe différente.

Nuage de points : base ↔︎ ggplot2

R de base

plot(sg$seagrass_cover,
     sg$canopy_height_cm, pch = 19,
     col = cols[sg$mpa_status],
     xlab = "Cover (%)",
     ylab = "Canopy (cm)")
legend("topleft", names(cols),
       col = cols, pch = 19, bty = "n")

ggplot2

ggplot(sg, aes(seagrass_cover,
               canopy_height_cm,
               colour = mpa_status)) +
  geom_point(na.rm = TRUE) +
  scale_colour_manual(values = cols) +
  labs(x = "Cover (%)",
       y = "Canopy (cm)") +
  theme_classic()

Séance 10 — Projet final

Le suivi corallien

  • 3 AMP (Ankaramena, Nosy Fasika, Tanjona — noms inventés, données simulées)
  • 2 zones par AMP : No-take (pêche interdite) et Fishing
  • 3 transects de 25 m par zone · 50 points par transect (PIT)
  • Fichier coral_cover_raw.csv : 910 lignes, saisi par 3 observateurs… et sale

Question : la couverture en corail dur est-elle plus élevée en zone No-take, et ce dans les trois AMP ?

La méthode PIT

Les étapes

Étape 1–2 : importer et nettoyer

raw <- read.csv("data/coral_cover_raw.csv")
length(unique(raw$mpa))                             # 15 orthographes !
#> [1] 15
raw$mpa <- tools::toTitleCase(tolower(trimws(gsub("\\s+", " ", raw$mpa))))
raw$zone[tolower(raw$zone) == "no-take"] <- "No-take"
raw$zone[tolower(raw$zone) == "fishing"] <- "Fishing"
raw$category <- toupper(trimws(raw$category))
raw$category[raw$category == ""] <- NA
pts <- raw[!duplicated(raw), ]
pts <- pts[!is.na(pts$category), ]
table(pts$mpa, pts$zone)
#>              
#>               Fishing No-take
#>   Ankaramena      147     147
#>   Nosy Fasika     148     146
#>   Tanjona         150     148

Étape 3 : la base de données (1 ligne = 1 transect)

pts$is_hc <- pts$category == "HC"           # TRUE si corail dur
db <- aggregate(is_hc ~ mpa + zone + transect, data = pts, FUN = mean)
db$hc_cover <- db$is_hc * 100               # moyenne de TRUE/FALSE = proportion
db$is_hc <- NULL
nrow(db)
#> [1] 18
head(db, 4)
#>           mpa    zone transect hc_cover
#> 1  Ankaramena Fishing        1 34.00000
#> 2 Nosy Fasika Fishing        1 36.00000
#> 3     Tanjona Fishing        1 16.00000
#> 4  Ankaramena No-take        1 38.77551

Étape 4 : moyenne et ET par AMP × zone

m <- tapply(db$hc_cover, list(db$zone, db$mpa), mean)
s <- tapply(db$hc_cover, list(db$zone, db$mpa), sd)
round(m, 1)
#>         Ankaramena Nosy Fasika Tanjona
#> Fishing       29.9        28.3    21.3
#> No-take       38.0        37.1    51.3
round(s, 1)
#>         Ankaramena Nosy Fasika Tanjona
#> Fishing        6.0        10.5     4.6
#> No-take        8.4        13.1     7.5

Étape 5 : la figure

m <- m[c("No-take", "Fishing"), ]; s <- s[c("No-take", "Fishing"), ]
bp <- barplot(m, beside = TRUE, ylim = c(0, max(m + s) * 1.15), las = 1,
              col = c("#1b7f8c", "#d9694a"), ylab = "Hard coral cover (%) ± SD (n = 3)")
arrows(bp, m - s, bp, m + s, angle = 90, code = 3, length = 0.05)
legend("topright", fill = c("#1b7f8c", "#d9694a"), legend = rownames(m), bty = "n")

Étape 6 : interpréter avec prudence

  • Où la couverture est-elle la plus forte ? L’effet No-take est-il le même partout ?
  • Limites : n = 3 transects par zone, ET élevés, données simulées
  • Une figure n’existe qu’avec sa légende : ce que montrent les barres, les barres d’erreur, et n

Le quiz final reprend chaque étape : nombre de lignes, doublons, points manquants, couverture d’un transect, moyennes et ET.
