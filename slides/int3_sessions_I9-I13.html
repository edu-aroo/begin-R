La loi normale et le QQ-plot

  • 68 % des valeurs dans moyenne ± 1 ET, 95 % dans ± 1,96 ET
  • QQ-plot : des données normales suivent la droite
qq <- function(x, t) ggplot(data.frame(x = x), aes(sample = x)) + stat_qq(alpha = .4) +
  stat_qq_line(colour = "#d9694a") + labs(title = t, x = NULL, y = NULL)
qq(inc, "revenu") | qq(log(inc), "log(revenu)")

Shapiro–Wilk : un complément, pas un juge

shapiro.test(inc)$p.value; shapiro.test(log(inc))$p.value
#> [1] 1.810141e-22
#> [1] 0.4517445
  • petit n : ne rejette presque jamais · grand n : rejette pour des écarts minimes
  • avec de grands groupes, les moyennes sont presque normales (théorème central limite)
Ordre : histogramme + QQ-plot → décision → (test de Shapiro en complément).

Une p-value, construite à la main

li <- log(inc); g <- hh$does_seaweed
obs <- mean(li[g]) - mean(li[!g]); exp(obs)      # +7,5 % pour les ménages algoculteurs
#> [1] 1.075095
set.seed(42)
perm <- replicate(5000, { s <- sample(g); mean(li[s]) - mean(li[!s]) })   # H0 : étiquettes au hasard
mean(abs(perm) >= abs(obs))                      # = la p-value
#> [1] 0.2166
p-value = probabilité d’un résultat au moins aussi extrême si H0 était vraie.

Ce qu’une p-value n’est pas

  • pas la probabilité que H0 soit vraie
  • non significatif ≠ pas d’effet : « pas de preuve d’une différence »
  • significatif ≠ important : regarder la taille d’effet et son IC
  • 0,05 est une convention : 0,049 ≈ 0,051

I10 — Choisir le bon test

Le schéma de décision

Paramétrique ou non paramétrique ?

Paramétrique Non paramétrique
utilise les valeurs (moyenne, ET) les rangs
suppose ~ normal (ou grands groupes) formes semblables
exemples t.test(), Pearson wilcox.test(), Spearman
+ plus puissant, effet en unités robuste aux extrêmes
Choisir avant de voir p. Ne pas faire les deux tests pour garder celui qui « marche ».

Deux moyennes indépendantes

tt <- t.test(sgr ~ season, data = seaweed)       # Welch par défaut
round(c(tt$estimate, diff = unname(diff(rev(tt$estimate))), tt$conf.int, p = tt$p.value), 3)
#> mean in group dry mean in group wet              diff                   
#>             3.563             3.302             0.261             0.207 
#>                                   p 
#>             0.314             0.000
wilcox.test(monthly_income_mga ~ head_sex, data = hh)$p.value   # revenu asymétrique
#> [1] 0.4250528

« Les algues ont poussé plus vite en saison sèche (3,56 vs 3,30 % j⁻¹ ; différence 0,26, IC 95 % 0,21–0,31 ; Welch t = 9,56, p < 0,001). »

Corrélation : Pearson ou Spearman

cor(wq$temp_C, wq$DO_mgL, use = "complete.obs")                                   # Pearson
#> [1] -0.5516088
cor(seaweed$temp_mean, seaweed$sgr, use = "complete.obs", method = "spearman")    # Spearman
#> [1] -0.1875033
ggplot(seaweed, aes(temp_mean, sgr)) + geom_jitter(width = .05, alpha = .15, na.rm = TRUE) +
  geom_smooth(method = "loess", formula = y ~ x, colour = "#d9694a", na.rm = TRUE)

Quand aucun coefficient ne convient

  • la croissance monte jusqu’à ~25–26 °C puis descend : relation forte mais non monotone
  • Pearson et Spearman ≈ −0,19 : ils mélangent les deux pentes
  • tracer avant de calculer ; décrire une courbe par le graphique
  • corrélation ≠ causalité · une question = un test (20 tests → ~1 faux positif)

I11 — Cartes avec ggplot2

Une carte = un nuage de points + un polygone

coast <- read.csv("data/coastline.csv"); villages <- read.csv("data/villages.csv")
growth <- seaweed %>% group_by(village) %>% summarise(m = mean(sgr, na.rm = TRUE))
gm <- left_join(villages, growth, by = "village")
ggplot() + geom_polygon(data = coast, aes(lon, lat), fill = "#efe6d2", colour = "grey50") +
  geom_point(data = gm, aes(lon, lat, fill = m), shape = 21, size = 4) +
  scale_fill_viridis_c(option = "mako", direction = -1, name = "SGR") +
  coord_quickmap(xlim = c(43.38, 43.88), ylim = c(-23.35, -22.55)) +
  theme(panel.background = element_rect(fill = "#d8ecf2", colour = NA))

Les points clés des cartes

  • x = longitude, y = latitude (sud = négatif), WGS84
  • coord_quickmap() : bon rapport d’aspect ; geom_polygon() : lignes dans l’ordre
  • résumer → joindre aux coordonnées → size (quantité) / fill (intensité)
  • flèche du nord et échelle avec annotate() (0,09° de latitude ≈ 10 km)
  • aperçu de sf (st_as_sf(), geom_sf()) → niveau avancé
