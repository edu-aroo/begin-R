Biomasse de poissons : 3 colonnes

Comptage visuel (UVC) : pour chaque groupe, l’espèce, la taille length_cm et le nombre count. Poids d’un poisson : W = a × L^b (paramètres FishBase).

fish$weight_g  <- fish$a * fish$length_cm^fish$b     # un poisson (g)
fish$biomass_g <- fish$count * fish$weight_g          # le groupe (g)
fish$kg_ha     <- fish$biomass_g / 1000 / 250 * 10000 # transect de 250 m²

Écart-type ou erreur standard ?

  • ET (SD) : variabilité entre quadrats — ne diminue pas avec n
  • ES (SE) = ET / √n : précision de la moyenne — diminue quand n augmente
sd(x) / sqrt(length(x))
#> [1] 1.759639
h <- sg$canopy_height_cm
sd(h, na.rm = TRUE) / sqrt(sum(!is.na(h)))   # n sans les NA
#> [1] 0.4946351
Toujours préciser dans la légende : barres = ET ou ES, et n.

Construire un tableau de synthèse

n_site    <- tapply(sg$seagrass_cover, sg$site, length)
mean_site <- tapply(sg$seagrass_cover, sg$site, mean)
sd_site   <- tapply(sg$seagrass_cover, sg$site, sd)
tab <- data.frame(site = names(mean_site), n = as.vector(n_site),
                  mean = round(as.vector(mean_site), 1),
                  sd = round(as.vector(sd_site), 1))
tab$se <- round(tab$sd / sqrt(tab$n), 1)
tab
#>         site  n mean   sd  se
#> 1  Ambalaboy 15 52.8 12.3 3.2
#> 2  Belitsaky 15 46.9 12.0 3.1
#> 3   Fasimena 15 52.6 12.6 3.3
#> 4 Tsiandamba 15 41.7 15.5 4.0

Une valeur par unité d’échantillonnage

Le transect (ou le quadrat) est le réplicat. Pour la biomasse de poissons : d’abord une valeur par transect, ensuite moyenne et ET par site.

tr <- aggregate(biomass_g ~ site + transect, data = fish, FUN = sum)
tr$kg_ha <- tr$biomass_g / 1000 / 250 * 10000
round(tapply(tr$kg_ha, tr$site, mean), 1)
#>     Ambola   Andavaka Belavenoke    Tsifota 
#>      183.0      422.8      469.3      178.2
round(tapply(tr$kg_ha, tr$site, sd), 1)
#>     Ambola   Andavaka Belavenoke    Tsifota 
#>      103.4      335.3      195.5      120.6
