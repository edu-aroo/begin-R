Session 9 & 10 — Workflow of an analysisSéances 9 et 10 — Déroulé d’une analyse

  1. Import and inspect (read.csv, str, unique, table(..., useNA = "always")).Importer et inspecter (read.csv, str, unique, table(..., useNA = "always")).
  2. Clean text, numbers, impossible values, duplicates, missing values — in the script.Nettoyer textes, nombres, valeurs impossibles, doublons, valeurs manquantes — dans le script.
  3. Build the database: one row per sampling unit (aggregate), save it.Construire la base : une ligne par unité d’échantillonnage (aggregate), l’enregistrer.
  4. Summarise: n, mean, SD, SE per group (tapply).Résumer : n, moyenne, ET, ES par groupe (tapply).
  5. Plot and save the figure; write a caption saying what the error bars are and n.Représenter et enregistrer la figure ; légende indiquant ce que sont les barres d’erreur et n.
  6. Interpret with care: sample size, variability, limits.Interpréter avec prudence : effectif, variabilité, limites.
