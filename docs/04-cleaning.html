4 · Selecting, filtering & cleaning data4 · Sélectionner, filtrer et nettoyer

~3 h

By the end of this session you will be able to

  • combine conditions with &, |, ! and %in%;
  • keep the rows and columns you need with [ , ] and subset();
  • sort a table with order();
  • detect and fix the classic problems of field data: inconsistent spelling, extra spaces, text in numeric columns, impossible values, duplicated rows, awkward column names.

À la fin de cette séance vous saurez

  • combiner des conditions avec &, |, ! et %in% ;
  • garder les lignes et colonnes utiles avec [ , ] et subset() ;
  • trier un tableau avec order() ;
  • détecter et corriger les problèmes classiques des données de terrain : orthographe incohérente, espaces en trop, texte dans des colonnes numériques, valeurs impossibles, lignes en double, noms de colonnes peu pratiques.

New script scripts/s04_cleaning.R. Start it by importing the clean dataset: sg <- read.csv("data/seagrass_quadrats.csv").

Nouveau script scripts/s04_cleaning.R. Commencez par importer le jeu de données propre : sg <- read.csv("data/seagrass_quadrats.csv").

Filtering rowsFiltrer des lignes

Put a condition in the row position of [ , ]. Do not forget the comma: sg[condition, ] means “these rows, all columns”.

Placez une condition à la position des lignes de [ , ]. N’oubliez pas la virgule : sg[condition, ] signifie « ces lignes, toutes les colonnes ».

inside <- sg[sg$mpa_status == "Inside", ]        # quadrats inside the MPA
nrow(inside)
#> [1] 30
dense_shallow <- sg[sg$seagrass_cover > 60 & sg$depth_m < 1.5, ]
dense_shallow[, c("site", "quadrat", "depth_m", "seagrass_cover")]
#>         site quadrat depth_m seagrass_cover
#> 4  Ambalaboy       4     0.4             61
#> 26  Fasimena      11     0.7             62
#> 30  Fasimena      15     0.7             61
#> 52 Belitsaky       7     0.8             61

subset() does the same with a lighter syntax: no sg$, no comma. The argument select chooses the columns.

subset() fait la même chose avec une syntaxe plus légère : pas de sg$, pas de virgule. L’argument select choisit les colonnes.

thal <- subset(sg, species == "Thalassia hemprichii" & mpa_status == "Outside",
               select = c(site, quadrat, seagrass_cover))
head(thal)
#>          site quadrat seagrass_cover
#> 32 Tsiandamba       2             64
#> 33 Tsiandamba       3             37
#> 36 Tsiandamba       6             41
#> 44 Tsiandamba      14             31
#> 46  Belitsaky       1             30
#> 47  Belitsaky       2             59
nrow(thal)
#> [1] 12

[ ] and NA. With sg[condition, ], rows where the condition is NA come back as rows full of NA. subset() simply drops them. When a column contains NA, prefer subset() or wrap the condition in which(): sg[which(sg$canopy_height_cm > 20), ].

[ ] et NA. Avec sg[condition, ], les lignes où la condition vaut NA reviennent sous forme de lignes remplies de NA. subset() les retire simplement. Quand une colonne contient des NA, préférez subset() ou entourez la condition de which() : sg[which(sg$canopy_height_cm > 20), ].

small <- sg[, c("site", "quadrat", "seagrass_cover")]   # keep 3 columns
small2 <- sg[, -c(4, 5)]                                # drop columns 4 and 5
names(small2)
#> [1] "site"             "mpa_status"       "quadrat"          "species"          "seagrass_cover"  
#> [6] "canopy_height_cm" "shoot_density"

order() returns the positions that would sort a vector; use it in the row position. Add decreasing = TRUE (or a minus sign for numbers) to sort from largest to smallest.

order() renvoie les positions qui trieraient un vecteur ; on l’utilise à la position des lignes. Ajoutez decreasing = TRUE (ou un signe moins pour les nombres) pour trier du plus grand au plus petit.

top <- sg[order(sg$seagrass_cover, decreasing = TRUE), c("site", "quadrat", "seagrass_cover")]
head(top, 5)                                   # the 5 densest quadrats
#>          site quadrat seagrass_cover
#> 28   Fasimena      13             74
#> 58  Belitsaky      13             72
#> 23   Fasimena       8             71
#> 42 Tsiandamba      12             71
#> 1   Ambalaboy       1             69
sg_sorted <- sg[order(sg$site, -sg$seagrass_cover), ]   # by site, then by cover (decreasing)

Fixing text: spaces and caseCorriger le texte : espaces et casse

Function What it does Example
trimws(x) removes spaces at the start and end " Tsiandamba" → "Tsiandamba"
tolower(x) / toupper(x) all lower / upper case "FASIMENA" → "fasimena"
tools::toTitleCase(x) capital first letter of each word "nosy fasika" → "Nosy Fasika"
gsub(old, new, x) replaces every occurrence of a pattern gsub("%", "", "45%") → "45"

tools::toTitleCase means “the function toTitleCase from the package tools” (installed with R). The :: lets you use a function without loading the whole package.

Fonction Ce qu’elle fait Exemple
trimws(x) retire les espaces au début et à la fin " Tsiandamba" → "Tsiandamba"
tolower(x) / toupper(x) tout en minuscules / majuscules "FASIMENA" → "fasimena"
tools::toTitleCase(x) majuscule au début de chaque mot "nosy fasika" → "Nosy Fasika"
gsub(ancien, nouveau, x) remplace toutes les occurrences d’un motif gsub("%", "", "45%") → "45"

tools::toTitleCase signifie « la fonction toTitleCase du package tools » (installé avec R). Le :: permet d’utiliser une fonction sans charger tout le package.

raw$site <- trimws(raw$site)                       # 1. remove extra spaces
raw$site <- tools::toTitleCase(tolower(raw$site))  # 2. same case everywhere
table(raw$site)                                    # 4 sites again
#> 
#>  Ambalaboy  Belitsaky   Fasimena Tsiandamba 
#>         16         16         15         15

Work on a copy, never on the original file. The CSV in data/ stays untouched; all corrections are written in the script. Anyone can see — and check — every change you made.

Travaillez sur une copie, jamais sur le fichier original. Le CSV dans data/ reste intact ; toutes les corrections sont écrites dans le script. N’importe qui peut voir — et vérifier — chaque modification effectuée.

Fixing numbers stored as textCorriger des nombres stockés en texte

First give the column a clean name, then look at the values that are not pure numbers.

Donnons d’abord un nom propre à la colonne, puis regardons les valeurs qui ne sont pas de simples nombres.

names(raw)[names(raw) == "Seagrass.cover...."] <- "seagrass_cover"   # rename one column
unique(raw$seagrass_cover)       # look for "%" and "-"
#>  [1] "69"  "47"  "64"  "61"  "53%" "27"  "52"  "48"  "55"  "56"  "-"   "59"  "26"  "53"  "57"  "51"  "31" 
#> [18] "51%" "30"  "71"  "41"  "62"  "74"  "130" "37"  "10"  "32"  "42"  "48%" "33"  "40"  "45"  "44"  "50" 
#> [35] "46"  "49"  "35"  "72"
raw$seagrass_cover <- gsub("%", "", raw$seagrass_cover)    # remove the % sign
raw$seagrass_cover[raw$seagrass_cover == "-"] <- NA        # "-" means not measured
raw$seagrass_cover <- as.numeric(raw$seagrass_cover)       # text -> number
summary(raw$seagrass_cover)
#>    Min. 1st Qu.  Median    Mean 3rd Qu.    Max.     NAs 
#>   10.00   40.75   50.00   49.73   59.00  130.00       2

Impossible values and duplicatesValeurs impossibles et doublons

A percentage cover cannot exceed 100. Look at the suspicious row before deciding: here it is clearly a typing error, and we cannot know the true value, so we replace it by NA (we keep the rest of the quadrat information).

Un pourcentage de recouvrement ne peut pas dépasser 100. Regardez la ligne suspecte avant de décider : ici c’est clairement une erreur de saisie, et on ne peut pas connaître la vraie valeur ; on la remplace donc par NA (on garde les autres informations du quadrat).

raw[which(raw$seagrass_cover > 100), ]                     # inspect
#>        site mpa_status quadrat       date depth_m                  species seagrass_cover canopy_height_cm
#> 29 Fasimena     Inside      14 2026-03-11     0.7 Syringodium isoetifolium            130             12.4
#>    shoot_density
#> 29           532
raw$seagrass_cover[which(raw$seagrass_cover > 100)] <- NA  # correct

duplicated() returns TRUE for each row that is an exact copy of a previous row.

duplicated() renvoie TRUE pour chaque ligne qui est la copie exacte d’une ligne précédente.

sum(duplicated(raw))          # how many duplicated rows?
#> [1] 2
raw[duplicated(raw), 1:4]     # which ones?
#>         site mpa_status quadrat       date
#> 61 Ambalaboy     Inside      15 2026-03-10
#> 62 Belitsaky    Outside       5 2026-03-13
clean <- raw[!duplicated(raw), ]    # keep only the first occurrence
nrow(clean)
#> [1] 60

Order matters. Fix the spelling before looking for duplicates: "Ambalaboy" and "Ambalaboy " (with a space) are not identical for R, so a duplicate could be missed.

L’ordre compte. Corrigez l’orthographe avant de chercher les doublons : "Ambalaboy" et "Ambalaboy " (avec un espace) ne sont pas identiques pour R ; un doublon pourrait être manqué.

Application work & quizTravail d’application et quiz

Application work 4

Part A — filtering (with the clean file seagrass_quadrats.csv)

  1. How many quadrats are dominated by Cymodocea serrulata and are shallower than 1.5 m (depth_m < 1.5)?

Part B — cleaning (with seagrass_messy.csv, in this order)

  1. Import the file. How many rows does it have?
  2. How many different spellings of site names are there before cleaning?
  3. Clean the site names (trimws, tolower, tools::toTitleCase) and rename the cover column seagrass_cover. How many rows are exact duplicates?
  4. Convert the cover to numbers (remove %, "-" → NA), set values > 100 to NA, and remove the duplicates. How many NA are there now in seagrass_cover?
  5. Mean seagrass cover of the clean data (ignore NA), rounded to 2 decimals.
  6. Mean cover at Belitsaky (ignore NA), rounded to 2 decimals.
  7. How many quadrats are Inside the MPA with a cover > 50 %? (use subset())

Travail d’application 4

Partie A — filtrer (avec le fichier propre seagrass_quadrats.csv)

  1. Combien de quadrats sont dominés par Cymodocea serrulata et sont à moins de 1,5 m (depth_m < 1.5) ?

Partie B — nettoyer (avec seagrass_messy.csv, dans cet ordre)

  1. Importez le fichier. Combien de lignes contient-il ?
  2. Combien d’orthographes différentes de noms de sites y a-t-il avant nettoyage ?
  3. Nettoyez les noms de sites (trimws, tolower, tools::toTitleCase) et renommez la colonne de recouvrement seagrass_cover. Combien de lignes sont des doublons exacts ?
  4. Convertissez le recouvrement en nombres (retirez %, "-" → NA), mettez les valeurs > 100 à NA, et retirez les doublons. Combien de NA y a-t-il maintenant dans seagrass_cover ?
  5. Recouvrement moyen des données propres (sans NA), arrondi à 2 décimales.
  6. Recouvrement moyen à Belitsaky (sans NA), arrondi à 2 décimales.
  7. Combien de quadrats sont Inside l’AMP avec un recouvrement > 50 % ? (utilisez subset())
# Part A
sg <- read.csv("data/seagrass_quadrats.csv")
nrow(subset(sg, species == "Cymodocea serrulata" & depth_m < 1.5))   # 1

# Part B
raw <- read.csv("data/seagrass_messy.csv")
nrow(raw)                                            # 2
length(unique(raw$site))                             # 3
raw$site <- tools::toTitleCase(tolower(trimws(raw$site)))
names(raw)[names(raw) == "Seagrass.cover...."] <- "seagrass_cover"
sum(duplicated(raw))                                 # 4
raw$seagrass_cover <- gsub("%", "", raw$seagrass_cover)
raw$seagrass_cover[raw$seagrass_cover == "-"] <- NA
raw$seagrass_cover <- as.numeric(raw$seagrass_cover)
raw$seagrass_cover[which(raw$seagrass_cover > 100)] <- NA
clean <- raw[!duplicated(raw), ]
sum(is.na(clean$seagrass_cover))                     # 5
round(mean(clean$seagrass_cover, na.rm = TRUE), 2)   # 6
round(mean(clean$seagrass_cover[clean$site == "Belitsaky"], na.rm = TRUE), 2)  # 7
nrow(subset(clean, mpa_status == "Inside" & seagrass_cover > 50))             # 8
