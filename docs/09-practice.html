What this session is for

No new concepts here: six independent exercises to practise what you learned in Sessions 2 to 8, before the final project. Each exercise has its own quiz (one attempt each) and its own solution, unlocked after you submit.

  • Do them in order or in any order; each starts by importing its data.
  • Write everything in one script scripts/s09_practice.R, with one section per exercise (Ctrl + Shift + R).
  • If you get less than 70 % on an exercise, re-read the session indicated before moving on.

À quoi sert cette séance

Pas de nouvelle notion ici : six exercices indépendants pour pratiquer ce que vous avez appris dans les séances 2 à 8, avant le projet final. Chaque exercice a son propre quiz (une seule tentative chacun) et sa propre solution, débloquée après validation.

  • Faites-les dans l’ordre ou non ; chacun commence par importer ses données.
  • Écrivez tout dans un seul script scripts/s09_practice.R, avec une section par exercice (Ctrl + Maj + R).
  • Si vous obtenez moins de 70 % à un exercice, relisez la séance indiquée avant de continuer.

Exercise 1 — Building vectorsExercice 1 — Créer des vecteurs

Revise: Session 2.

  1. How many values does seq(1, 10, by = 0.75) contain?
  2. Build labels <- paste0("Q", rep(1:5, times = 3), "_", rep(c("A", "B", "C"), each = 5)). What is labels[7]?
  3. Run set.seed(7), then draw 6 PIT positions with sample(seq(0.5, 25, by = 0.5), 6). What is the largest position drawn?
  4. With x <- c(12, 45, 7, 88, 23, 56): what is the second smallest value (use sort())?
  5. What is the sum of the first two values of rev(x)?

Révision : séance 2.

  1. Combien de valeurs contient seq(1, 10, by = 0.75) ?
  2. Créez labels <- paste0("Q", rep(1:5, times = 3), "_", rep(c("A", "B", "C"), each = 5)). Que vaut labels[7] ?
  3. Lancez set.seed(7), puis tirez 6 positions PIT avec sample(seq(0.5, 25, by = 0.5), 6). Quelle est la plus grande position tirée ?
  4. Avec x <- c(12, 45, 7, 88, 23, 56) : quelle est la deuxième plus petite valeur (utilisez sort()) ?
  5. Quelle est la somme des deux premières valeurs de rev(x) ?
length(seq(1, 10, by = 0.75))            # 1
labels <- paste0("Q", rep(1:5, times = 3), "_", rep(c("A", "B", "C"), each = 5))
labels[7]                                 # 2. "Q2_B": 7th number is 2, 7th letter is B
set.seed(7)
s <- sample(seq(0.5, 25, by = 0.5), 6)
max(s)                                    # 3
x <- c(12, 45, 7, 88, 23, 56)
sort(x)[2]                                # 4
sum(rev(x)[1:2])                          # 5. rev(x) starts with 56, 23

  2. Somme de seagrass_cover sur les lignes 1 à 5 (une seule ligne avec [ligne, colonne]).

sg <- read.csv("data/seagrass_quadrats.csv")
sg[17, "species"]                                   # 1
sum(sg[1:5, "seagrass_cover"])                      # 2
round(mean(sg[46:60, "shoot_density"]), 2)          # 3
sg2 <- sg
sg2$depth_m[sg2$depth_m < 0.6] <- 0.6               # 4. condition inside [ ]
round(mean(sg2$depth_m), 2)
sum(is.na(sg$canopy_height_cm))                     # 5

  1. Nombre total de poissons observés (somme de count).
  2. Ajoutez biomass_kg = count × a × length_cm^b / 1000. Quelle est la plus grande valeur de biomass_kg (3 décimales) ?
  3. Ajoutez n_per_ha = count / 250 × 10000 (poissons par hectare). Valeur à la ligne 10 ?
  4. Supprimez les colonnes family, a et b en une ligne avec subset(..., select = -c(...)). Combien de colonnes reste-t-il ?

fish <- read.csv("data/fish_uvc.csv")
sum(fish$count)                                                  # 1
fish$biomass_kg <- fish$count * fish$a * fish$length_cm^fish$b / 1000
round(max(fish$biomass_kg), 3)                                   # 2
fish$n_per_ha <- fish$count / 250 * 10000
fish[10, "n_per_ha"]                                             # 3
fish <- subset(fish, select = -c(family, a, b))
ncol(fish)                                                       # 4
sapply(fish[, c("length_cm", "count", "biomass_kg")], mean)      # 5

Révision : séance 5. Données : réimportez fish <- read.csv("data/fish_uvc.csv") (l’exercice 3 a supprimé des colonnes).

  1. Combien de lignes sont des vivaneaux ou des mérous (Lutjanus kasmira ou Epinephelus merra, utilisez %in%) hors AMP ?
  2. Combien de colonnes garde subset(fish, length_cm > 25, select = site:species) ?

  4. Nettoyez x <- c(" Ifaty", "ifaty", "IFATY ", "Mangily", "mangily ") avec trimws(), tolower() et tools::toTitleCase(). Combien de valeurs différentes reste-t-il ?
  5. Nettoyez y <- c("12", "15%", "-", "40", "8%") : retirez %, transformez "-" en NA, convertissez en nombres. Moyenne de y sans NA ?
fish <- read.csv("data/fish_uvc.csv")
nrow(subset(fish, mpa_status == "Outside" &
                  species %in% c("Lutjanus kasmira", "Epinephelus merra")))     # 1
ncol(subset(fish, length_cm > 25, select = site:species))                     # 2
round(mean(subset(fish, family == "Scaridae" & mpa_status == "Inside")$length_cm), 2)  # 3
x <- c(" Ifaty", "ifaty", "IFATY ", "Mangily", "mangily ")
length(unique(tools::toTitleCase(tolower(trimws(x)))))                       # 4
y <- c("12", "15%", "-", "40", "8%")
y <- gsub("%", "", y)
y[y == "-"] <- NA
mean(as.numeric(y), na.rm = TRUE)                                            # 5

Exercise 5 — Statistics per groupExercice 5 — Statistiques par groupe

Revise: Session 6. Data: fish, with a column biomass_g = count × a × length_cm^b.

  1. Total number of fish counted at Ambola (tapply() with sum).
  2. Mean length_cm inside the MPA with aggregate(length_cm ~ mpa_status, ...) (2 decimals).
  3. SD of length_cm for Scarus ghobban (2 decimals).
  4. Two steps. (a) Total biomass per transect: aggregate(biomass_g ~ mpa_status + site + transect, data = fish, FUN = sum). (b) Convert to kg/ha (÷ 1000, ÷ 250, × 10000). (c) Mean kg/ha of the Inside transects (2 decimals)?
  5. SE of the kg/ha of the Outside transects (2 decimals)?

Révision : séance 6. Données : fish, avec une colonne biomass_g = count × a × length_cm^b.

  1. Nombre total de poissons comptés à Ambola (tapply() avec sum).
  2. Moyenne de length_cm dans l’AMP avec aggregate(length_cm ~ mpa_status, ...) (2 décimales).
  3. ET de length_cm pour Scarus ghobban (2 décimales).
  4. Deux étapes. (a) Biomasse totale par transect : aggregate(biomass_g ~ mpa_status + site + transect, data = fish, FUN = sum). (b) Convertir en kg/ha (÷ 1000, ÷ 250, × 10000). (c) Moyenne des kg/ha des transects Inside (2 décimales) ?
  5. ES des kg/ha des transects Outside (2 décimales) ?
fish <- read.csv("data/fish_uvc.csv")
fish$biomass_g <- fish$count * fish$a * fish$length_cm^fish$b
tapply(fish$count, fish$site, sum)                                  # 1
aggregate(length_cm ~ mpa_status, data = fish, FUN = mean)          # 2
round(sd(fish$length_cm[fish$species == "Scarus ghobban"]), 2)      # 3
tr <- aggregate(biomass_g ~ mpa_status + site + transect, data = fish, FUN = sum)
tr$kg_ha <- tr$biomass_g / 1000 / 250 * 10000
round(tapply(tr$kg_ha, tr$mpa_status, mean), 2)                     # 4
out <- tr$kg_ha[tr$mpa_status == "Outside"]
round(sd(out) / sqrt(length(out)), 2)                               # 5. n = 6 transects

Exercise 6 — Graphs and equivalencesExercice 6 — Graphiques et équivalences

  1. Draw boxplot(length_cm ~ family, data = fish, las = 2). Which family has the highest median length?

Révision : séances 7 et 8. Données : réimportez fish <- read.csv("data/fish_uvc.csv") (l’exercice 3 a supprimé des colonnes).

  1. Tracez boxplot(length_cm ~ family, data = fish, las = 2). Quelle famille a la médiane de taille la plus élevée ?
  2. Tracez h <- hist(fish$length_cm, breaks = seq(0, 40, by = 5)). Combien de groupes de poissons se trouvent dans la classe de taille la plus fréquente (h$counts) ?
  3. Faites le même boxplot avec ggplot2.
  4. Répondez aux questions sur les équivalences entre R de base et le tidyverse.
fish <- read.csv("data/fish_uvc.csv")
boxplot(length_cm ~ family, data = fish, las = 2, xlab = "")
tapply(fish$length_cm, fish$family, median)          # 1: check the highest
h <- hist(fish$length_cm, breaks = seq(0, 40, by = 5))
h$counts; max(h$counts)                               # 2
library(ggplot2)                                      # 3
ggplot(fish, aes(family, length_cm)) + geom_boxplot() +
  theme_classic() + theme(axis.text.x = element_text(angle = 45, hjust = 1))
