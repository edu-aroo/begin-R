A10 · Practice sessionA10 · Séance d’exercices

~3.5 h

What this session is for

No new concepts: six independent exercises to practise Sessions A0 to A9 before the final project. Each exercise has its own quiz (two attempts, the best one counts) and its own solution. The final project opens when the six exercises together reach 75 % of their points.

  • Work in your reef-monitoring project: one script R/10_practice.R, one section per exercise.
  • All files come from the Advanced data zip (data/advanced/): copy what you need into data/raw/.
  • Hints are free.

À quoi sert cette séance

Pas de nouvelle notion : six exercices indépendants pour pratiquer les séances A0 à A9 avant le projet final. Chaque exercice a son propre quiz (deux tentatives, la meilleure compte) et sa propre solution. Le projet final s’ouvre quand les six exercices réunis atteignent 75 % de leurs points.

  • Travaillez dans votre projet reef-monitoring : un script R/10_practice.R, une section par exercice.
  • Tous les fichiers viennent du zip des données avancées (data/advanced/) : copiez ce dont vous avez besoin dans data/raw/.
  • Les indices sont gratuits.

Data (simulated). The monitoring programme of the three MPAs, described in Session A0: coral transects 2019–2025, the mangrove inventory 2025, the GIS layers, the bathymetry and sea temperature rasters, the NGO project with its Git history and the example lockfile.

Données (simulées). Le programme de suivi des trois AMP, décrit à la séance A0 : transects coralliens 2019–2025, inventaire des mangroves 2025, couches SIG, rasters de bathymétrie et de température de la mer, projet de l’ONG avec son historique Git et le fichier lock d’exemple.

  1. Mean macroalgae cover of Tanjona in 2021 (1 decimal)?

Séances A3–A4. Écrivez une fonction mpa_summary(reef, mpa, year) qui renvoie le nombre de transects, le corail dur moyen et les macroalgues moyennes d’une AMP pour une année — le cœur d’un rapport paramétré.

  1. Recouvrement moyen en macroalgues de Tanjona en 2021 (1 décimale) ?
  2. Nombre de transects de la zone No-take d’Ankaramena en 2020 ?
  3. Un rapport est fait pour chaque AMP et chaque année avec des données. Combien de rapports pour 2019–2025 (pensez à 2022 à Tanjona) ?

library(dplyr)
reef <- left_join(read.csv("data/raw/reef_monitoring.csv"), read.csv("data/raw/reef_sites.csv"), by = "site_id")
mpa_summary <- function(reef, mpa, year) {
  d <- reef[reef$mpa == mpa & reef$year == year, ]
  data.frame(mpa = mpa, year = year, transects = nrow(d),
             hard_coral = mean(d$hard_coral), macroalgae = mean(d$macroalgae))
}
mpa_summary(reef, "Tanjona", 2021)                                       # 1
sum(reef$mpa == "Ankaramena" & reef$zone == "No-take" & reef$year == 2020)  # 2
nrow(distinct(reef, mpa, year))                                          # 3: 7 + 7 + 6

Séance A5. Couches mpa_zones et mangrove_plots de monitoring_gis.gpkg.

  1. Surface totale des zones Fishing de Nosy Fasika (km², 1 décimale) ?
  2. Combien de placettes de mangrove sont à moins de 5 km d’une zone No-take ?
  3. Fusionnez les zones en trois AMP. Pour combien de placettes Tanjona est-elle l’AMP la plus proche (st_nearest_feature()) ?

Both layers are already in UTM (metres). st_nearest_feature(plots, mpas) returns, for each plot, the row number of the nearest MPA: use it to read mpas$mpa[...].

Les deux couches sont déjà en UTM (mètres). st_nearest_feature(placettes, amp) renvoie, pour chaque placette, le numéro de ligne de l’AMP la plus proche : utilisez-le pour lire amp$mpa[...].

library(sf); library(dplyr)
zones <- st_read("data/raw/monitoring_gis.gpkg", "mpa_zones")
plots <- st_read("data/raw/monitoring_gis.gpkg", "mangrove_plots")
nf <- filter(zones, mpa == "Nosy Fasika", zone == "Fishing")
sum(as.numeric(st_area(nf))) / 1e6                                       # 1
nt <- st_union(filter(zones, zone == "No-take"))
sum(as.numeric(st_distance(plots, nt)) < 5000)                           # 2
mpas <- zones %>% group_by(mpa) %>% summarise()
sum(mpas$mpa[st_nearest_feature(plots, mpas)] == "Tanjona")              # 3

Exercise 5 — Mangrove indicatorsExercice 5 — Indicateurs mangrove

Sessions A0, A8. Clean the trees as in Session A8 (upper-case codes; DBH > 30 cm on trees < 8 m divided by 10). Plot area = π × 10² m².

  1. Mean basal area of living trees in the reference plots (m²/ha, 1 decimal). Basal area of one trunk = π × (DBH / 200)² m².
  2. In the plots of status restored, what percentage of the trees are dead (1 decimal)?
  3. Mean stem density of living trees in the harvested plots (stems/ha, no decimal)?

Séances A0, A8. Nettoyez les arbres comme à la séance A8 (codes en majuscules ; DHP > 30 cm sur des arbres < 8 m divisés par 10). Surface d’une placette = π × 10² m².

  1. Surface terrière moyenne des arbres vivants dans les placettes de référence (m²/ha, 1 décimale). Surface terrière d’un tronc = π × (DHP / 200)² m².
  2. Dans les placettes de statut restored, quel pourcentage des arbres est mort (1 décimale) ?
  3. Densité moyenne des tiges vivantes dans les placettes harvested (tiges/ha, sans décimale) ?

The tree table has a status (alive, dead, cut) and the plot table also has a status (reference, harvested, restored): after joining, rename one of them, or use suffix = in left_join(). Compute per plot first, then average the plots.

Le tableau des arbres a un status (alive, dead, cut) et celui des placettes aussi (reference, harvested, restored) : après la jointure, renommez l’un des deux, ou utilisez suffix = dans left_join(). Calculez d’abord par placette, puis faites la moyenne des placettes.

library(dplyr)
trees <- read.csv("data/raw/mangrove_trees.csv") %>%
  mutate(species_code = toupper(species_code),
         dbh_cm = ifelse(dbh_cm > 30 & height_m < 8, dbh_cm / 10, dbh_cm),
         ba_m2 = pi * (dbh_cm / 200)^2)
plots <- read.csv("data/raw/mangrove_plots.csv")
area_ha <- pi * 10^2 / 1e4
trees <- left_join(trees, plots[, c("plot_id", "status")], by = "plot_id", suffix = c("", "_plot"))
per_plot <- trees %>% filter(status == "alive") %>% group_by(plot_id, status_plot) %>%
  summarise(ba_ha = sum(ba_m2) / area_ha, stems_ha = n() / area_ha, .groups = "drop")
per_plot %>% group_by(status_plot) %>% summarise(ba = mean(ba_ha), stems = mean(stems_ha))   # 1, 3
trees %>% filter(status_plot == "restored") %>% summarise(dead = 100 * mean(status == "dead"))  # 2

  2. Answer the questions on maps and publishing.

Séances A7, A9.

  1. Calculez le corail dur moyen de chaque site en 2019 et en 2025. Dans combien de sites le recouvrement était-il plus élevé en 2025 qu’en 2019 ? Cartographiez-les (une couleur pour « plus élevé », une pour « plus faible »).
  2. Répondez aux questions sur les cartes et la publication.
library(dplyr); library(tidyr); library(sf); library(ggplot2)
reef  <- read.csv("data/raw/reef_monitoring.csv")
sites <- st_read("data/raw/monitoring_gis.gpkg", "reef_sites")
ch <- reef %>% filter(year %in% c(2019, 2025)) %>% group_by(site_id, year) %>%
  summarise(m = mean(hard_coral), .groups = "drop") %>%
  pivot_wider(names_from = year, values_from = m, names_prefix = "y") %>%
  mutate(trend = ifelse(y2025 > y2019, "higher", "lower"))
sum(ch$trend == "higher")                                                # 1
ggplot() + geom_sf(data = st_read("data/raw/monitoring_gis.gpkg", "land"), fill = "#efe6d2") +
  geom_sf(data = left_join(sites, ch, by = "site_id"), aes(colour = trend), size = 2) +
  coord_sf(xlim = st_bbox(sites)[c(1, 3)] + c(-5000, 5000), ylim = st_bbox(sites)[c(2, 4)] + c(-5000, 5000))
