WelcomeBienvenue

This course takes you from zero (R is not even installed) to a complete, reproducible analysis of coral reef and seagrass survey data. It is designed for self-study: every session explains the reasoning, shows the code and its result, and ends with an application exercise followed by a quiz where you enter the numbers you obtained.

You only need a computer (Windows, macOS or Linux) and about 31 hours in total, spread over 11 sessions. A cheatsheet (menu bar) summarises every function of the course.

Ce cours vous emmène de zéro (R n’est même pas installé) jusqu’à une analyse complète et reproductible de données de suivi des récifs coralliens et des herbiers marins. Il est conçu pour l’auto-formation : chaque séance explique le raisonnement, montre le code et son résultat, et se termine par un travail d’application suivi d’un quiz où vous saisissez les valeurs obtenues.

Il vous faut seulement un ordinateur (Windows, macOS ou Linux) et environ 31 heures au total, réparties en 11 séances. Un aide-mémoire (barre de menu) résume toutes les fonctions du cours.

How to use this courseComment utiliser ce cours

  1. Follow the sessions in order. Each one builds on the previous one.
  2. Type the code yourself in RStudio rather than only copying it: your fingers learn too. The Copy button is there for long blocks.
  3. At the end of each section, click “Mark this section as done”. Your progress is saved automatically: next time you log in, you go back exactly where you stopped.
  4. Do the application work in your own script, then enter your results in the quiz. Each quiz can be submitted only once: check your answers in your script before submitting. Your score is final and recorded.
  5. The solution of each exercise unlocks once you have submitted the quiz. Study it, especially for the questions you got wrong.
  1. Suivez les séances dans l’ordre. Chacune s’appuie sur la précédente.
  2. Tapez le code vous-même dans RStudio au lieu de seulement le copier : vos doigts apprennent aussi. Le bouton Copier sert pour les longs blocs.
  3. À la fin de chaque section, cliquez sur « Marquer cette section comme terminée ». Votre progression est enregistrée automatiquement : à la prochaine connexion, vous revenez exactement là où vous vous êtes arrêté.
  4. Faites le travail d’application dans votre propre script, puis saisissez vos résultats dans le quiz. Chaque quiz ne peut être validé qu’une seule fois : vérifiez vos réponses dans votre script avant de valider. Votre score est définitif et enregistré.
  5. La solution de chaque exercice se débloque une fois le quiz validé. Étudiez-la, surtout pour les questions manquées.
