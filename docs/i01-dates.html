I1 · DatesI1 · Les dates

~2.5 h

By the end of this session you will be able to

  • convert text and Excel date-times into real dates with as.Date() and its format;
  • extract the year, month, day of week; compute durations between two dates;
  • create seasons and periods from dates;
  • use lubridate to do the same with shorter code;
  • compute the seaweed growth rate of each line.

À la fin de cette séance vous saurez

  • convertir du texte et des dates-heures Excel en vraies dates avec as.Date() et son format ;
  • extraire l’année, le mois, le jour de la semaine ; calculer des durées entre deux dates ;
  • créer des saisons et des périodes à partir des dates ;
  • utiliser lubridate pour faire la même chose avec un code plus court ;
  • calculer le taux de croissance des algues de chaque ligne.

Start from your I0 script, or from the checkpoint file: lines <- read.csv("data/checkpoints/I0_lines.csv"). With the checkpoint, planting_date is text "2024-01-08", so convert it with as.Date() first.

Partez de votre script I0, ou du fichier de contrôle : lines <- read.csv("data/checkpoints/I0_lines.csv"). Avec le fichier de contrôle, planting_date est du texte "2024-01-08" : convertissez-le d’abord avec as.Date().

⇩ checkpoint: I0_lines.csv

Why dates need special carePourquoi les dates demandent de l’attention

To R, "22/02/2024" is just text: it cannot compute that 45 days separate planting and harvest, nor sort dates correctly ("02/03/2024" would come before "22/02/2024" in alphabetical order). A Date object stores the number of days since 1 January 1970, which makes all calculations possible.

Pour R, "22/02/2024" n’est que du texte : il ne peut pas calculer que 45 jours séparent le semis de la récolte, ni trier correctement les dates ("02/03/2024" passerait avant "22/02/2024" dans l’ordre alphabétique). Un objet Date stocke le nombre de jours depuis le 1er janvier 1970, ce qui rend tous les calculs possibles.

d <- as.Date("2024-01-08")       # the international format yyyy-mm-dd is read directly
class(d)
#> [1] "Date"
as.numeric(d)                    # days since 1970-01-01
#> [1] 19730
d + 45                           # 45 days later
#> [1] "2024-02-22"

Text to date: as.Date() and formatDu texte à la date : as.Date() et format

When the text is not yyyy-mm-dd, tell R how it is written with format codes:

Code Meaning Example
%d day (01–31) 08
%m month number (01–12) 03
%b / %B month name, short / full (in the computer’s language) Mar / March
%y / %Y year, 2 / 4 digits 24 / 2024
%A day of the week Monday

Quand le texte n’est pas en aaaa-mm-jj, indiquez à R comment il est écrit avec des codes de format :

Code Signification Exemple
%d jour (01–31) 08
%m numéro du mois (01–12) 03
%b / %B nom du mois, court / complet (dans la langue de l’ordinateur) mars / mars
%y / %Y année, 2 / 4 chiffres 24 / 2024
%A jour de la semaine lundi 
as.Date("22/02/2024", format = "%d/%m/%Y")
#> [1] "2024-02-22"
as.Date("02-22-24", format = "%m-%d-%y")
#> [1] "2024-02-22"
lines$harvest_date[1:3]
#> [1] "22/02/2024" "20/02/2024" "26/02/2024"
lines$harvest_date <- as.Date(lines$harvest_date, format = "%d/%m/%Y")
lines$harvest_date[1:3]
#> [1] "2024-02-22" "2024-02-20" "2024-02-26"

If the format does not match the text, as.Date() returns NA without error. Always check: sum(is.na(x)) before and after conversion must be equal.

Excel dates read as numbers (e.g. 45299): as.Date(45299, origin = "1899-12-30"). Date-times (POSIXct, from readxl): as.Date(x).

Si le format ne correspond pas au texte, as.Date() renvoie NA sans erreur. Vérifiez toujours : sum(is.na(x)) avant et après conversion doivent être égaux.

Dates Excel lues comme des nombres (ex. 45299) : as.Date(45299, origin = "1899-12-30"). Dates-heures (POSIXct, de readxl) : as.Date(x).

Durations, parts of a date, sequencesDurées, parties d’une date, séquences

lines$days <- as.numeric(lines$harvest_date - lines$planting_date)   # difference in days
summary(lines$days)
#>    Min. 1st Qu.  Median    Mean 3rd Qu.    Max. 
#>   40.00   42.00   45.00   45.02   48.00   50.00
format(lines$planting_date[1:3], "%Y")                  # year as text
#> [1] "2024" "2024" "2024"
as.integer(format(lines$planting_date[1:3], "%m"))      # month as a number
#> [1] 1 1 1
format(as.Date("2024-01-08"), "%d %B %Y")               # nice label for a report
#> [1] "08 January 2024"
difftime(as.Date("2025-12-31"), as.Date("2024-01-01"), units = "weeks")
#> Time difference of 104.2857 weeks
seq(as.Date("2024-01-01"), by = "month", length.out = 4)   # monthly sampling calendar
#> [1] "2024-01-01" "2024-02-01" "2024-03-01" "2024-04-01"

Seasons and periodsSaisons et périodes

In this region the wet season runs from November to April, the dry season from May to October. A season is a category built from the month number with %in% and ifelse() (ifelse() will be studied in detail in Session I5).

Dans cette région, la saison des pluies va de novembre à avril, la saison sèche de mai à octobre. Une saison est une catégorie construite à partir du numéro du mois avec %in% et ifelse() (ifelse() sera étudié en détail en séance I5).

lines$year   <- as.integer(format(lines$planting_date, "%Y"))
lines$month  <- as.integer(format(lines$planting_date, "%m"))
lines$season <- ifelse(lines$month %in% c(11, 12, 1, 2, 3, 4), "wet", "dry")
table(lines$year, lines$season)
#>       
#>        dry wet
#>   2024 692 696
#>   2025 652 535

cut() groups dates into periods, for example quarters:

cut() regroupe les dates en périodes, par exemple en trimestres :

head(cut(lines$planting_date, breaks = "quarter"))
#> [1] 2024-01-01 2024-01-01 2024-01-01 2024-01-01 2024-01-01 2024-01-01
#> Levels: 2024-01-01 2024-04-01 2024-07-01 2024-10-01 2025-01-01 2025-04-01 2025-07-01 2025-10-01

The same with lubridateLa même chose avec lubridate

lubridate (tidyverse) has functions named after the order of the parts: dmy() for day-month-year, ymd(), mdy()… No format codes to remember. And year(), month(), wday() extract parts directly as numbers.

lubridate (tidyverse) propose des fonctions nommées d’après l’ordre des éléments : dmy() pour jour-mois-année, ymd(), mdy()… Pas de codes de format à retenir. Et year(), month(), wday() extraient directement les éléments sous forme de nombres.

R base

as.Date("22/02/2024", format = "%d/%m/%Y")
#> [1] "2024-02-22"
as.integer(format(as.Date("2024-02-22"), "%m"))
#> [1] 2
as.Date("2024-02-22") + 30
#> [1] "2024-03-23"

lubridate

library(lubridate)
dmy("22/02/2024")
#> [1] "2024-02-22"
month(ymd("2024-02-22"))
#> [1] 2
ymd("2024-02-22") + days(30)
#> [1] "2024-03-23"
dmy(c("22/02/2024", "3-4-2024", "05.06.2024"))   # tolerant to separators
#> [1] "2024-02-22" "2024-04-03" "2024-06-05"
floor_date(ymd("2024-02-22"), "month")          # first day of the month
#> [1] "2024-02-01"

Growth rate of each lineTaux de croissance de chaque ligne

Seaweed farmers and researchers compare lines with the specific growth rate (SGR), in % per day:

SGR = 100 × ln(final weight / initial weight) / number of days

It accounts for different initial weights and cycle lengths. Values of 3–5 %/day are usual for Kappaphycus.

Producteurs et chercheurs comparent les lignes avec le taux de croissance spécifique (SGR), en % par jour :

SGR = 100 × ln(poids final / poids initial) / nombre de jours

Il tient compte des poids initiaux et des durées de cycle différents. Des valeurs de 3 à 5 %/jour sont habituelles pour Kappaphycus.

i <- which(lines$final_weight_kg > 200)                  # weights typed in grams (I0)
lines$final_weight_kg[i] <- lines$final_weight_kg[i] / 1000
lines$sgr <- 100 * log(lines$final_weight_kg / lines$initial_weight_kg) / lines$days
summary(lines$sgr)
#>    Min. 1st Qu.  Median    Mean 3rd Qu.    Max.     NAs 
#>   1.405   2.967   3.445   3.439   3.882   5.456     258
round(tapply(lines$sgr, lines$season, mean, na.rm = TRUE), 2)
#>  dry  wet 
#> 3.56 3.30

Application work & quizTravail d’application et quiz

Application work I1

Script scripts/i01_dates.R, with the sheet lines (or the checkpoint file).

  1. Convert harvest_date to a date. What is the earliest harvest date (yyyy-mm-dd)?
  2. Add days (harvest − planting). Mean duration (2 decimals)? Longest duration?
  3. Add year, month (from the planting date) and season. How many lines were planted in 2025?
  4. In which month (number 1–12) were the most lines planted?
  5. How many lines were planted in the wet season?
  6. Correct the weights in grams, then compute sgr. Mean SGR of all lines (3 decimals, ignore NA)? Mean SGR in the dry season (3 decimals)?
  7. How many days between 1 January 2024 and 31 December 2025?

Travail d’application I1

Script scripts/i01_dates.R, avec la feuille lines (ou le fichier de contrôle).

  1. Convertissez harvest_date en date. Quelle est la première date de récolte (aaaa-mm-jj) ?
  2. Ajoutez days (récolte − semis). Durée moyenne (2 décimales) ? Durée la plus longue ?
  3. Ajoutez year, month (à partir de la date de semis) et season. Combien de lignes ont été semées en 2025 ?
  4. Quel mois (numéro 1–12) compte le plus de lignes semées ?
  5. Combien de lignes ont été semées en saison des pluies ?
  6. Corrigez les poids en grammes, puis calculez sgr. SGR moyen de toutes les lignes (3 décimales, sans NA) ? SGR moyen en saison sèche (3 décimales) ?
  7. Combien de jours entre le 1er janvier 2024 et le 31 décembre 2025 ?

Question 4: table(lines$month) then which.max(); the answer is the name of the cell, i.e. the month number. Question 6: the log is log() (natural logarithm) in R.

Question 4 : table(lines$month) puis which.max() ; la réponse est le nom de la case, c’est-à-dire le numéro du mois. Question 6 : le logarithme népérien est log() dans R.

library(readxl)
lines <- read_excel("data/seaweed_farming.xlsx", sheet = "lines", skip = 3)
lines$planting_date <- as.Date(lines$planting_date)
lines$harvest_date  <- as.Date(lines$harvest_date, format = "%d/%m/%Y")
min(lines$harvest_date)                                              # 1
lines$days <- as.numeric(lines$harvest_date - lines$planting_date)
round(mean(lines$days), 2); max(lines$days)                          # 2
lines$year   <- as.integer(format(lines$planting_date, "%Y"))
lines$month  <- as.integer(format(lines$planting_date, "%m"))
lines$season <- ifelse(lines$month %in% c(11, 12, 1, 2, 3, 4), "wet", "dry")
sum(lines$year == 2025)                                              # 3
which.max(table(lines$month))                                        # 4 (the name is the month)
sum(lines$season == "wet")                                           # 5
i <- which(lines$final_weight_kg > 200)
lines$final_weight_kg[i] <- lines$final_weight_kg[i] / 1000
lines$sgr <- 100 * log(lines$final_weight_kg / lines$initial_weight_kg) / lines$days
round(mean(lines$sgr, na.rm = TRUE), 3)                              # 6a
round(mean(lines$sgr[lines$season == "dry"], na.rm = TRUE), 3)       # 6b
as.numeric(as.Date("2025-12-31") - as.Date("2024-01-01"))            # 7
