A11 · Final project: the 2026 monitoring reports, reproducible and publishedA11 · Projet final : les rapports de suivi 2026, reproductibles et publiés

~5 h

In this project you will, on your own

  • set up a reproducible project (structure, here, renv, Git) from the start;
  • add a new year of raw field data to the monitoring table, with every correction written in a script;
  • produce one Quarto report per MPA (HTML and PDF) with values in the text, cross-referenced figures and tables, a map, the mangrove results and citations;
  • version the project and publish the reports online.

This is the last quiz of the Advanced level (two attempts, the best one counts).

Dans ce projet, vous allez, en autonomie

  • mettre en place dès le départ un projet reproductible (arborescence, here, renv, Git) ;
  • ajouter une nouvelle année de données brutes de terrain au tableau du suivi, chaque correction étant écrite dans un script ;
  • produire un rapport Quarto par AMP (HTML et PDF) avec des valeurs dans le texte, des figures et tableaux avec renvois, une carte, les résultats mangroves et des citations ;
  • versionner le projet et publier les rapports en ligne.

C’est le dernier quiz du niveau avancé (deux tentatives, la meilleure compte).

Simulated context. The 2026 field campaign has just ended (April–May 2026). Three observers surveyed the same 18 reef sites with the same method (three 20 m Point Intercept Transects per site), and a fourth observer (TS) joined the team. The data were typed by the observers in a shared sheet and sent as reef_monitoring_2026.csv. As every year, the file is not perfect: the dates were typed dd/mm/yyyy instead of yyyy-mm-dd, a few site codes are in lower case (r12), two values of hard coral were typed without the decimal point (312 instead of 31.2), and two rows were entered twice. The MPA managers expect the three 2026 reports before their June meeting, and the NGO wants them online.

Type: the same as reef_monitoring.csv (one row = one transect and one year; percentages), plus the GIS layers, rasters and mangrove inventory of the previous sessions.

Contexte simulé. La campagne de terrain 2026 vient de se terminer (avril–mai 2026). Trois observateurs ont suivi les mêmes 18 sites récifaux avec la même méthode (trois Point Intercept Transects de 20 m par site), et un quatrième observateur (TS) a rejoint l’équipe. Les données ont été saisies par les observateurs dans un tableur partagé et envoyées sous le nom reef_monitoring_2026.csv. Comme chaque année, le fichier n’est pas parfait : les dates ont été saisies jj/mm/aaaa au lieu de aaaa-mm-jj, quelques codes de sites sont en minuscules (r12), deux valeurs de corail dur ont été saisies sans la virgule (312 au lieu de 31,2), et deux lignes ont été saisies deux fois. Les gestionnaires des AMP attendent les trois rapports 2026 avant leur réunion de juin, et l’ONG les veut en ligne.

Type : le même que reef_monitoring.csv (une ligne = un transect et une année ; pourcentages), plus les couches SIG, rasters et l’inventaire des mangroves des séances précédentes.

# ==============================================================================
# R/02_clean_2026.R — add the 2026 campaign to the monitoring table (final project)
# Reads  data/raw/reef_monitoring.csv (2019-2025) and data/raw/reef_monitoring_2026.csv
# Writes data/derived/reef_2019_2026.csv
# ==============================================================================
library(dplyr)
library(here)

old <- read.csv(here("data", "raw", "reef_monitoring.csv"))
new <- read.csv(here("data", "raw", "reef_monitoring_2026.csv"))

# 1. Look before you clean -------------------------------------------------------
nrow(new)
sum(duplicated(new))                      # rows typed twice
setdiff(unique(new$site_id), unique(old$site_id))   # site codes that do not exist
summary(new$hard_coral)                   # values > 100 % ?

# 2. Clean (every correction is written here, never in the raw file) ------------
new <- new %>%
  distinct() %>%                                                    # TO DO: check the number of rows removed
  mutate(site_id     = toupper(site_id),                            # "r07" -> "R07"
         survey_date = format(as.Date(survey_date, format = "%d/%m/%Y"), "%Y-%m-%d"),   # same format as old
         hard_coral  = ifelse(hard_coral > 100, hard_coral / 10, hard_coral))           # decimal point forgotten

# 3. Same columns, then stack the years -----------------------------------------
stopifnot(identical(names(old), names(new)))
all <- bind_rows(old, new)
dir.create(here("data", "derived"), showWarnings = FALSE)
write.csv(all, here("data", "derived", "reef_2019_2026.csv"), row.names = FALSE)
message("Rows 2019-2026: ", nrow(all))

Order matters: remove the exact duplicates first (distinct()), then fix the codes and values — otherwise a row typed twice is counted twice in your means. If bind_rows() complains, the two tables do not have the same column types: compare str(old) and str(new) (the date!).

L’ordre compte : supprimez d’abord les doublons exacts (distinct()), puis corrigez les codes et les valeurs — sinon une ligne saisie deux fois serait comptée deux fois dans vos moyennes. Si bind_rows() proteste, les deux tableaux n’ont pas les mêmes types de colonnes : comparez str(old) et str(new) (la date !).

For the map of change, compute the mean cover per site and year, keep 2025 and 2026, pivot_wider(), compute y2026 - y2025, and join to sites (sites first). For the mangrove table, the plot table has a patch column: filter the patch of the MPA, then summarise per status.

Pour la carte de variation, calculez le recouvrement moyen par site et par année, gardez 2025 et 2026, pivot_wider(), calculez y2026 - y2025, et joignez à sites (les sites en premier). Pour le tableau mangroves, le tableau des placettes a une colonne patch : filtrez le massif de l’AMP, puis résumez par status.
