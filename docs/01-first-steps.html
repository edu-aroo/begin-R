1 · First steps: objects & functions1 · Premiers pas : objets et fonctions

~2 h

By the end of this session you will be able to

  • use R as a calculator and understand the order of operations;
  • store values in objects with <- and re-use them;
  • call functions with arguments, and read a help page;
  • write, comment, save and re-run a script.

À la fin de cette séance vous saurez

  • utiliser R comme une calculatrice et comprendre l’ordre des opérations ;
  • stocker des valeurs dans des objets avec <- et les réutiliser ;
  • appeler des fonctions avec des arguments, et lire une page d’aide ;
  • écrire, commenter, enregistrer et relancer un script.

Open your project R_course_reef, create a new script (Ctrl + Shift + N) and save it as scripts/s01_first_steps.R. Type every example of this page in it and run each line with Ctrl + Enter.

Ouvrez votre projet R_course_reef, créez un nouveau script (Ctrl + Maj + N) et enregistrez-le sous scripts/s01_first_steps.R. Tapez chaque exemple de cette page dedans et exécutez chaque ligne avec Ctrl + Entrée.

Data of this session (simulated). No data file yet. The numbers of this session are typical values written on a field sheet during a reef and seagrass survey: the size of a quadrat (50 × 50 cm), a number of shoots counted, the length of a transect, the size of a no-take zone. Type: single numbers (measurements and counts).

Données de cette séance (simulées). Pas encore de fichier. Les nombres de cette séance sont des valeurs typiques d’une fiche de terrain lors d’un suivi récif et herbier : la taille d’un quadrat (50 × 50 cm), un nombre de pousses comptées, la longueur d’un transect, la surface d’une zone de non-prélèvement. Type : des nombres isolés (mesures et comptages).

R as a calculatorR comme calculatrice

In the boxes below, the grey box with a coloured left border is the code you type; the box underneath, starting with #>, is what R answers. The [1] means “first value of the result”.

Dans les cadres ci-dessous, le cadre gris avec une bordure colorée à gauche est le code que vous tapez ; le cadre en dessous, commençant par #>, est la réponse de R. Le [1] signifie « première valeur du résultat ».

12 + 30        # addition
#> [1] 42
100 - 37       # subtraction
#> [1] 63
4 * 25         # multiplication
#> [1] 100
87 / 0.25      # division: 87 shoots counted in a 0.25 m2 quadrat -> shoots per m2
#> [1] 348
2^3            # power: 2 x 2 x 2
#> [1] 8

R follows the usual order of operations: powers, then multiplication/division, then addition/subtraction. Use parentheses to be explicit.

R respecte l’ordre habituel des opérations : puissances, puis multiplication/division, puis addition/soustraction. Utilisez des parenthèses pour être explicite.

10 + 5 * 2      # = 10 + 10
#> [1] 20
(10 + 5) * 2    # = 15 * 2
#> [1] 30

Field example. On a 20 m transect, the tape crosses live hard coral over a total of 7.4 m. The percentage of hard coral cover is 7.4 / 20 * 100.

Exemple de terrain. Sur un transect de 20 m, le ruban passe au-dessus de corail dur vivant sur 7,4 m au total. Le pourcentage de couverture en corail dur est 7.4 / 20 * 100.

7.4 / 20 * 100
#> [1] 37

R uses the dot as decimal separator: write 7.4, never 7,4. A comma separates the arguments of a function (see below).

R utilise le point comme séparateur décimal : écrivez 7.4, jamais 7,4. La virgule sépare les arguments d’une fonction (voir plus bas).

Objects: giving a name to a valueObjets : donner un nom à une valeur

Typing the same number again and again is error-prone. Instead, store it in an object with the assignment arrow <- (type < then -, or use the shortcut Alt + −). Read x <- 5 as “x gets 5”.

Taper le même nombre encore et encore est source d’erreurs. Il vaut mieux le stocker dans un objet avec la flèche d’affectation <- (tapez < puis -, ou utilisez le raccourci Alt + −). Lisez x <- 5 comme « x reçoit 5 ».

quadrat_area <- 0.5 * 0.5      # a 50 x 50 cm quadrat, in m2
shoots       <- 87             # number of seagrass shoots counted
density      <- shoots / quadrat_area
density                        # typing the name prints the value
#> [1] 348

Nothing is printed when you create an object: R stores it silently, and the object appears in the Environment pane. If you assign a new value to the same name, the old one is replaced without warning.

Rien ne s’affiche lors de la création d’un objet : R le stocke en silence, et l’objet apparaît dans le panneau Environment. Si vous affectez une nouvelle valeur au même nom, l’ancienne est remplacée sans avertissement.

shoots <- 112                  # a new count replaces the old one
shoots / quadrat_area          # density must be recalculated!
#> [1] 448
density                        # still the OLD value: objects do not update by themselves
#> [1] 348

Naming rulesRègles de nommage

  • Names may contain letters, numbers, _ and ., but must start with a letter: site1 ✔, 1site ✘.
  • No spaces: coral cover ✘ → use coral_cover ✔ (this “snake_case” style is recommended).
  • R is case-sensitive: Cover, cover and COVER are three different objects.
  • Choose explicit names: mean_cover_inside is better than m1.
  • Les noms peuvent contenir des lettres, des chiffres, _ et ., mais doivent commencer par une lettre : site1 ✔, 1site ✘.
  • Pas d’espace : coral cover ✘ → utilisez coral_cover ✔ (ce style « snake_case » est recommandé).
  • R est sensible à la casse : Cover, cover et COVER sont trois objets différents.
  • Choisissez des noms explicites : mean_cover_inside vaut mieux que m1.

Functions and argumentsFonctions et arguments

A function is a ready-made tool: you give it inputs (arguments) inside parentheses, it returns a result. Arguments are separated by commas and can be named.

Une fonction est un outil prêt à l’emploi : on lui donne des entrées (arguments) entre parenthèses, elle renvoie un résultat. Les arguments sont séparés par des virgules et peuvent être nommés.

# function(argument1, argument2 = value, ...)
sqrt(144)                   # square root
#> [1] 12
round(348.6667)             # rounds to the nearest whole number
#> [1] 349
round(348.6667, digits = 1) # the argument "digits" sets the number of decimals
#> [1] 348.7
round(348.6667, 1)          # same: arguments can be given by position
#> [1] 348.7
log(100, base = 10)         # logarithm in base 10
#> [1] 2
exp(1)                      # the number e
#> [1] 2.718282
abs(-3.2)                   # absolute value
#> [1] 3.2

Functions can be nested: R evaluates from the inside out.

Les fonctions peuvent être imbriquées : R évalue de l’intérieur vers l’extérieur.

round(sqrt(2), 3)           # first sqrt(2) = 1.41421..., then round(..., 3)
#> [1] 1.414

How arguments work — valid for every function of the course:

  • Each argument has a name (x, digits, base). You can give it by name (round(3.14159, digits = 2)) or by position, in the order shown on the help page (round(3.14159, 2)). Names make code easier to read: use them for everything except the first argument.
  • Many arguments have a default value (digits = 0): you only give them when you want something else.
  • Each function has its own argument names, chosen by whoever wrote it. The same idea can have different names in different functions: the number of decimals is digits in round() but nsmall in format(); the colour is col in plot() (Session 7) but colour in ggplot2 (Session 8). Never guess: check the help page (?round) — the Usage section lists the arguments with their default values.

Comment marchent les arguments — valable pour toutes les fonctions du cours :

  • Chaque argument a un nom (x, digits, base). On peut le donner par son nom (round(3.14159, digits = 2)) ou par sa position, dans l’ordre indiqué dans la page d’aide (round(3.14159, 2)). Les noms rendent le code plus lisible : utilisez-les pour tous les arguments sauf le premier.
  • Beaucoup d’arguments ont une valeur par défaut (digits = 0) : on ne les donne que si l’on veut autre chose.
  • Chaque fonction a ses propres noms d’arguments, choisis par la personne qui l’a écrite. La même idée peut avoir des noms différents selon la fonction : le nombre de décimales s’appelle digits dans round() mais nsmall dans format() ; la couleur s’appelle col dans plot() (séance 7) mais colour dans ggplot2 (séance 8). Ne devinez jamais : consultez la page d’aide (?round) — la section Usage liste les arguments avec leurs valeurs par défaut.

Getting helpObtenir de l’aide

Every function has a help page. Type ? followed by the name; the page opens in the Help pane. The most useful parts are Usage (the arguments and their default values), Arguments and, at the bottom, Examples.

Chaque fonction possède une page d’aide. Tapez ? suivi du nom ; la page s’ouvre dans le panneau Help. Les parties les plus utiles sont Usage (les arguments et leurs valeurs par défaut), Arguments et, tout en bas, Examples.

?round                 # help page of round()
help("log")            # same thing
??"standard deviation" # search all help pages for a topic

Scripts and commentsScripts et commentaires

Everything after a # is a comment: R ignores it. Comments explain why you do something. A good script starts with a header and is organised in sections. In RStudio, Ctrl + Shift + R inserts a section heading, which you can then find in the outline (icon at the top-right of the script pane).

Tout ce qui suit un # est un commentaire : R l’ignore. Les commentaires expliquent pourquoi on fait quelque chose. Un bon script commence par un en-tête et est organisé en sections. Dans RStudio, Ctrl + Maj + R insère un titre de section, que l’on retrouve ensuite dans le sommaire (icône en haut à droite du panneau script).

# ==============================================================
# Session 1 - First steps in R
# Author : <your name>
# Date   : 2026-11-03
# ==============================================================

# ---- 1. Seagrass density -------------------------------------
quadrat_area <- 0.5 * 0.5    # m2
shoots <- 87
shoots / quadrat_area        # shoots per m2

Useful keys: Ctrl + Enter runs the current line (or the selected lines); Ctrl + Shift + Enter runs the whole script; Ctrl + S saves; ↑ in the console recalls the previous command.

Touches utiles : Ctrl + Entrée exécute la ligne courante (ou les lignes sélectionnées) ; Ctrl + Maj + Entrée exécute tout le script ; Ctrl + S enregistre ; ↑ dans la console rappelle la commande précédente.

Reading error messagesLire les messages d’erreur

Errors are normal, even for experts. Read the message: it usually tells you what is wrong.

Les erreurs sont normales, même pour les experts. Lisez le message : il dit généralement ce qui ne va pas.

Shoots / quadrat_area     # capital S: this object does not exist
#> Error:
#> ! object 'Shoots' not found
round(3.456, decimals = 1) # wrong argument name: round() calls it "digits"
#> Error in `round()`:
#> ! unused argument (decimals = 1)

The + prompt. If the console shows + instead of >, R is waiting for the end of an unfinished command (a missing ) or "). Press Esc to cancel and correct your line.

L’invite +. Si la console affiche + au lieu de >, R attend la fin d’une commande inachevée (une ) ou un " manquant). Appuyez sur Échap pour annuler et corrigez votre ligne.

Application work 1

In your script scripts/s01_first_steps.R, using objects (no number typed twice):

  1. A seagrass quadrat of 50 × 50 cm contains 132 shoots. Compute the shoot density per m².
  2. On a 20 m transect, live hard coral was recorded over 7.4 m. Compute the percentage of hard coral cover.
  3. The no-take zone of an MPA is a rectangle of 1.8 km × 0.75 km. Compute its area in km², then in hectares (1 km² = 100 ha).
  4. Round the result of sqrt(1000) to 2 decimals.
  5. Answer the quiz with your results.

Travail d’application 1

Dans votre script scripts/s01_first_steps.R, en utilisant des objets (aucun nombre tapé deux fois) :

  1. Un quadrat d’herbier de 50 × 50 cm contient 132 pousses. Calculez la densité de pousses par m².
  2. Sur un transect de 20 m, du corail dur vivant a été noté sur 7,4 m. Calculez le pourcentage de couverture en corail dur.
  3. La zone de non-prélèvement d’une AMP est un rectangle de 1,8 km × 0,75 km. Calculez sa surface en km², puis en hectares (1 km² = 100 ha).
  4. Arrondissez le résultat de sqrt(1000) à 2 décimales.
  5. Répondez au quiz avec vos résultats.

Question 1: the quadrat area is 0.5 × 0.5 = 0.25 m², and density = shoots / area. Question 2: cover (%) = 100 × length of coral / length of the transect. Question 3: compute the area in km² first, then multiply by 100.

Question 1 : la surface du quadrat vaut 0,5 × 0,5 = 0,25 m², et densité = pousses / surface. Question 2 : couverture (%) = 100 × longueur de corail / longueur du transect. Question 3 : calculez d’abord la surface en km², puis multipliez par 100.

# 1. Seagrass shoot density
side_m       <- 0.5                     # 50 cm = 0.5 m
quadrat_area <- side_m * side_m         # 0.25 m2
shoots       <- 132
shoots / quadrat_area                   # 528 shoots per m2

# 2. Hard coral cover along the transect
transect_length <- 20
coral_length    <- 7.4
coral_length / transect_length * 100    # 37 %

# 3. Area of the no-take zone
area_km2 <- 1.8 * 0.75                  # 1.35 km2
area_km2 * 100                          # 135 ha

# 4. Rounding
round(sqrt(1000), 2)                    # 31.62
