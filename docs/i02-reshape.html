I2 · Reshaping tablesI2 · Restructurer des tableaux

~2.5 h

By the end of this session you will be able to

  • recognise wide and long formats and know which one each task needs;
  • go from wide to long with pivot_longer() and from long to wide with pivot_wider();
  • split and join columns with separate() and unite();
  • replace error codes by NA and summarise many parameters at once.

À la fin de cette séance vous saurez

  • reconnaître les formats large et long et savoir lequel chaque tâche demande ;
  • passer du large au long avec pivot_longer() et du long au large avec pivot_wider() ;
  • séparer et réunir des colonnes avec separate() et unite() ;
  • remplacer des codes d’erreur par NA et résumer plusieurs paramètres d’un coup.

How the water-quality data were collectedComment les données de qualité de l’eau ont été collectées

Simulated context. To understand differences in seaweed growth, the cooperative and a partner NGO measured the water at 10 fixed stations (stations.csv: position, zone, depth) twice a month for 3 years (2023–2025), with a handheld multiparameter probe lowered at mid-depth: temperature (°C), salinity (PSU), pH, dissolved oxygen (mg/L) and turbidity (NTU). When the temperature sensor failed, the probe recorded the error code -999; a faulty pH electrode sometimes gave 0. Oxygen is missing when the sensor was being recalibrated.

The NGO also sent a summary file prepared in Excel, with one row per station and one column per month (monthly mean temperature).

Type of data: environmental time series — repeated physico-chemical measurements at fixed sites (quantitative, continuous).

Contexte simulé. Pour comprendre les différences de croissance des algues, la coopérative et une ONG partenaire ont mesuré l’eau à 10 stations fixes (stations.csv : position, zone, profondeur) deux fois par mois pendant 3 ans (2023–2025), avec une sonde multiparamètre descendue à mi-profondeur : température (°C), salinité (PSU), pH, oxygène dissous (mg/L) et turbidité (NTU). Quand le capteur de température tombait en panne, la sonde enregistrait le code d’erreur -999 ; une électrode de pH défectueuse donnait parfois 0. L’oxygène manque quand le capteur était en recalibrage.

L’ONG a aussi envoyé un fichier de synthèse préparé dans Excel, avec une ligne par station et une colonne par mois (température moyenne mensuelle).

Type de données : séries temporelles environnementales — mesures physico-chimiques répétées sur des sites fixes (quantitatives, continues).

Wide or long?Large ou long ?

The same information can be stored in two ways:

  • Wide: one row per station, one column per month (or per parameter). Easy to read by eye, typical of Excel reports.
  • Long: one row per measurement, with a column saying what was measured and a column with the value. Needed by ggplot2 (colour or facet by parameter), by group_by() + summarise(), and by statistical tests.

Rule of thumb: store and analyse in long format, present in wide format.

La même information peut être rangée de deux façons :

  • Large : une ligne par station, une colonne par mois (ou par paramètre). Facile à lire à l’œil, typique des rapports Excel.
  • Long : une ligne par mesure, avec une colonne indiquant ce qui a été mesuré et une colonne pour la valeur. Nécessaire pour ggplot2 (couleur ou panneau par paramètre), pour group_by() + summarise(), et pour les tests statistiques.

Règle pratique : stocker et analyser en format long, présenter en format large.

library(dplyr); library(tidyr)
wide <- read.csv("data/water_quality_wide.csv", check.names = FALSE)   # keep "2023-01" as names
wide[1:3, 1:6]
#>   station 2023-01 2023-02 2023-03 2023-04 2023-05
#> 1    WQ01    28.2    29.0    28.4    27.5    25.3
#> 2    WQ02    29.0    28.7    28.7    27.5    25.7
#> 3    WQ03    29.0    28.6    28.1    27.3    25.3
dim(wide)
#> [1] 10 37

Wide to long: pivot_longer()Du large au long : pivot_longer()

pivot_longer() takes the columns you list (cols), puts their names in a new column (names_to) and their values in another (values_to).

pivot_longer() prend les colonnes indiquées (cols), met leurs noms dans une nouvelle colonne (names_to) et leurs valeurs dans une autre (values_to).

long <- wide %>%
  pivot_longer(cols = -station,            # every column except station
               names_to = "month",
               values_to = "temp_mean")
head(long)
#> # A tibble: 6 × 3
#>   station month   temp_mean
#>   <chr>   <chr>       <dbl>
#> 1 WQ01    2023-01      28.2
#> 2 WQ01    2023-02      29  
#> 3 WQ01    2023-03      28.4
#> 4 WQ01    2023-04      27.5
#> 5 WQ01    2023-05      25.3
#> 6 WQ01    2023-06      24.6
dim(long)                                  # 10 stations x 36 months = 360 rows
#> [1] 360   3

Splitting a column: separate()Séparer une colonne : separate()

"2023-01" holds two pieces of information. separate() splits it; convert = TRUE turns the pieces into numbers. unite() does the opposite.

"2023-01" contient deux informations. separate() les sépare ; convert = TRUE transforme les morceaux en nombres. unite() fait l’inverse.

long <- long %>% separate(month, into = c("year", "month"), sep = "-", convert = TRUE)
head(long, 3)
#> # A tibble: 3 × 4
#>   station  year month temp_mean
#>   <chr>   <int> <int>     <dbl>
#> 1 WQ01     2023     1      28.2
#> 2 WQ01     2023     2      29  
#> 3 WQ01     2023     3      28.4
long %>% unite("period", year, month, sep = "/") %>% head(2)
#> # A tibble: 2 × 3
#>   station period temp_mean
#>   <chr>   <chr>      <dbl>
#> 1 WQ01    2023/1      28.2
#> 2 WQ01    2023/2      29

Several parameters: clean, then pivotPlusieurs paramètres : nettoyer, puis pivoter

The visit file has one column per parameter. First replace the error codes by NA, then pivot the five parameter columns. A range of columns temp_C:turbidity_NTU selects all columns between the two.

Le fichier des visites a une colonne par paramètre. Remplacez d’abord les codes d’erreur par NA, puis pivotez les cinq colonnes de paramètres. Une plage de colonnes temp_C:turbidity_NTU sélectionne toutes les colonnes entre les deux.

wq <- read.csv("data/water_quality_long.csv")
wq$date <- as.Date(wq$date, format = "%d/%m/%Y")
wq$temp_C[wq$temp_C == -999] <- NA          # error code of the temperature sensor
wq$pH[wq$pH == 0] <- NA                     # faulty pH electrode
wq_tidy <- wq %>%
  pivot_longer(temp_C:turbidity_NTU, names_to = "parameter", values_to = "value")
head(wq_tidy)
#> # A tibble: 6 × 4
#>   station date       parameter     value
#>   <chr>   <date>     <chr>         <dbl>
#> 1 WQ01    2023-01-05 temp_C        28.7 
#> 2 WQ01    2023-01-05 salinity_psu  33.3 
#> 3 WQ01    2023-01-05 pH             8.17
#> 4 WQ01    2023-01-05 DO_mgL         7.24
#> 5 WQ01    2023-01-05 turbidity_NTU  2.8 
#> 6 WQ02    2023-01-05 temp_C        29

Long to wide: pivot_wider()Du long au large : pivot_wider()

For a report table — one row per station, one column per parameter — use pivot_wider(): names_from gives the new column names, values_from the values.

Pour un tableau de rapport — une ligne par station, une colonne par paramètre — utilisez pivot_wider() : names_from donne les noms des nouvelles colonnes, values_from les valeurs.

station_table <- wq_tidy %>%
  group_by(station, parameter) %>%
  summarise(mean = round(mean(value, na.rm = TRUE), 2), .groups = "drop") %>%
  pivot_wider(names_from = parameter, values_from = mean)

library(dplyr); library(tidyr)
wide <- read.csv("data/water_quality_wide.csv", check.names = FALSE)
long <- wide %>% pivot_longer(-station, names_to = "month", values_to = "temp_mean") %>%
  separate(month, into = c("year", "month"), sep = "-", convert = TRUE)
nrow(long)                                                                  # 1
round(mean(long$temp_mean[long$year == 2024 & long$month == 7]), 2)         # 2

wq <- read.csv("data/water_quality_long.csv")
wq$date <- as.Date(wq$date, format = "%d/%m/%Y")
wq$temp_C[wq$temp_C == -999] <- NA
wq$pH[wq$pH == 0] <- NA
sum(is.na(wq$temp_C))                                                       # 3
tidy <- wq %>% pivot_longer(temp_C:turbidity_NTU, names_to = "parameter", values_to = "value")
nrow(tidy)                                                                  # 4
round(mean(tidy$value[tidy$parameter == "DO_mgL"], na.rm = TRUE), 3)        # 5
st <- tidy %>% group_by(station, parameter) %>%
  summarise(m = mean(value, na.rm = TRUE), .groups = "drop") %>%
  pivot_wider(names_from = parameter, values_from = m)
st$station[which.max(st$turbidity_NTU)]; ncol(st)                           # 6
tidy %>% mutate(year = format(date, "%Y")) %>% filter(parameter == "salinity_psu") %>%
  group_by(year) %>% summarise(m = round(mean(value, na.rm = TRUE), 3))     # 7
