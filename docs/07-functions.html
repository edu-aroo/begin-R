The PIT methodLa méthode PIT

In coral reef monitoring, the Point Intercept Transect records the benthic category found directly under the tape at regular intervals. Each row of the data is one point. The cover of a category on a transect is simply the percentage of points in that category.

En suivi des récifs coralliens, le transect à points (PIT) note la catégorie benthique située juste sous le ruban à intervalles réguliers. Chaque ligne de données est un point. La couverture d’une catégorie sur un transect est simplement le pourcentage de points dans cette catégorie.

pit <- read.csv("data/coral_pit_example.csv")
head(pit)
#>     reef transect point distance_m category
#> 1 Reef_A        1     1        0.5       RB
#> 2 Reef_A        1     2        1.0       TA
#> 3 Reef_A        1     3        1.5       TA
#> 4 Reef_A        1     4        2.0       TA
#> 5 Reef_A        1     5        2.5       SD
#> 6 Reef_A        1     6        3.0       SD
table(pit$reef, pit$transect)      # 50 points per transect
#>         
#>           1  2  3
#>   Reef_A 50 50 50
#>   Reef_B 50 50 50

if and elseif et else

if (condition) { ... } else { ... } runs one block or the other depending on one TRUE/FALSE value.

if (condition) { ... } else { ... } exécute un bloc ou l’autre selon une seule valeur TRUE/FALSE.

hc_cover <- 34
if (hc_cover >= 50) {
  print("High coral cover")
} else if (hc_cover >= 25) {
  print("Moderate coral cover")
} else {
  print("Low coral cover")
}
#> [1] "Moderate coral cover"

if only works with a single value. To classify a whole vector, use ifelse(condition, value_if_TRUE, value_if_FALSE), which can be nested:

if ne fonctionne qu’avec une seule valeur. Pour classer un vecteur entier, utilisez ifelse(condition, valeur_si_TRUE, valeur_si_FALSE), que l’on peut imbriquer :

covers <- c(12, 34, 58, 25, 71)
ifelse(covers >= 50, "High", ifelse(covers >= 25, "Moderate", "Low"))
#> [1] "Low"      "Moderate" "High"     "Moderate" "High"

cut() does the same for many classes at once:

cut() fait la même chose pour plusieurs classes d’un coup :

cut(covers, breaks = c(0, 25, 50, 100), labels = c("Low", "Moderate", "High"), right = FALSE)
#> [1] Low      Moderate High     Moderate High    
#> Levels: Low Moderate High

for loopsBoucles for

A for loop repeats a block of code once for each value of a vector. Read for (r in reefs) as “for each reef r in the list of reefs, do …”.

Une boucle for répète un bloc de code une fois pour chaque valeur d’un vecteur. Lisez for (r in reefs) comme « pour chaque récif r de la liste des récifs, faire … ».

reefs <- unique(pit$reef)
for (r in reefs) {
  points_r <- pit$category[pit$reef == r]          # all points of this reef
  hc <- sum(points_r == "HC") / length(points_r) * 100
  cat(r, ": hard coral =", round(hc, 1), "%\n")     # cat() prints; \n = new line
}
#> Reef_A : hard coral = 37.3 %
#> Reef_B : hard coral = 18 %

Loops are easy to understand, but in R you often do not need them: tapply() and vectorised functions do the same job in one line. Use a loop when each step is complex (e.g. reading several files, making one graph per site).

Les boucles sont faciles à comprendre, mais en R on en a souvent pas besoin : tapply() et les fonctions vectorisées font le même travail en une ligne. Utilisez une boucle quand chaque étape est complexe (ex. lire plusieurs fichiers, faire un graphique par site).

Writing your own functionsÉcrire ses propres fonctions

When you copy-paste the same code three times, write a function. The structure is:

name <- function(argument1, argument2 = default) {
  # ... calculations ...
  result          # the last value is returned
}

Quand vous copiez-collez le même code trois fois, écrivez une fonction. La structure est :

nom <- function(argument1, argument2 = valeur_par_defaut) {
  # ... calculs ...
  resultat        # la dernière valeur est renvoyée
}
# Standard error, ignoring missing values
se <- function(x) {
  x <- x[!is.na(x)]          # remove NA
  sd(x) / sqrt(length(x))
}
se(c(45, 60, 12, NA, 80))
#> [1] 14.33745

A function to compute the percentage cover of any benthic category, with hard coral as the default:

Une fonction qui calcule le pourcentage de couverture de n’importe quelle catégorie benthique, avec le corail dur par défaut :

pct_cover <- function(categories, code = "HC") {
  categories <- categories[!is.na(categories)]       # ignore missing points
  sum(categories == code) / length(categories) * 100
}

t1 <- pit$category[pit$reef == "Reef_A" & pit$transect == 1]
pct_cover(t1)                  # hard coral (default)
#> [1] 26
pct_cover(t1, code = "MA")     # macroalgae
#> [1] 16

One value per transectUne valeur par transect

Our own function works inside tapply() like any built-in function. Grouping by a list() of two variables gives one cover per reef × transect:

Notre fonction s’utilise dans tapply() comme n’importe quelle fonction intégrée. Grouper par une list() de deux variables donne une couverture par récif × transect :

tapply(pit$category, list(pit$reef, pit$transect), pct_cover)
#>         1  2  3
#> Reef_A 26 50 36
#> Reef_B 20 12 22

aggregate() gives the same result as a data frame — one row per transect. This “one row per sampling unit” table is the database you will need for statistics and graphs.

aggregate() donne le même résultat sous forme de data frame — une ligne par transect. Ce tableau « une ligne par unité d’échantillonnage » est la base de données dont vous aurez besoin pour les statistiques et les graphiques.

transects <- aggregate(category ~ reef + transect, data = pit, FUN = pct_cover)
names(transects)[3] <- "hc_cover"          # rename the result column
transects
#>     reef transect hc_cover
#> 1 Reef_A        1       26
#> 2 Reef_B        1       20
#> 3 Reef_A        2       50
#> 4 Reef_B        2       12
#> 5 Reef_A        3       36
#> 6 Reef_B        3       22
tapply(transects$hc_cover, transects$reef, mean)   # mean of the 3 transects per reef
#>   Reef_A   Reef_B 
#> 37.33333 18.00000
tapply(transects$hc_cover, transects$reef, sd)
#>    Reef_A    Reef_B 
#> 12.055428  5.291503

Why not simply count all points of a reef together? The transect is the replicate (the sampling unit), not the point: points on the same tape are not independent. So we first compute one cover per transect, then the mean and SD across transects. This is exactly what you will do in the final project.

Pourquoi ne pas simplement compter tous les points d’un récif ensemble ? Le transect est le réplicat (l’unité d’échantillonnage), pas le point : les points d’un même ruban ne sont pas indépendants. On calcule donc d’abord une couverture par transect, puis la moyenne et l’ET entre transects. C’est exactement ce que vous ferez dans le projet final.

pit <- read.csv("data/coral_pit_example.csv")

pct_cover <- function(categories, code = "HC") {
  categories <- categories[!is.na(categories)]
  sum(categories == code) / length(categories) * 100
}

tr <- aggregate(category ~ reef + transect, data = pit, FUN = pct_cover)
names(tr)[3] <- "hc_cover"
tr                                                   # 2: read Reef_B / 2
sum(tr$hc_cover > 30)                                # 3
round(tapply(tr$hc_cover, tr$reef, mean), 2)         # 4
round(tapply(tr$hc_cover, tr$reef, sd), 2)           # 5

ma <- aggregate(category ~ reef + transect, data = pit, FUN = pct_cover, code = "MA")
round(tapply(ma$category, ma$reef, mean), 2)         # 6

tr$class <- ifelse(tr$hc_cover >= 50, "High",
                   ifelse(tr$hc_cover >= 25, "Moderate", "Low"))
table(tr$class)                                      # 7

for (r in unique(pit$reef)) {                        # 8
  cat(r, ":", round(pct_cover(pit$category[pit$reef == r]), 1), "%\n")
}
