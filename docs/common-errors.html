Common errors and how to fix themErreurs fréquentes et comment les corriger

Read the message: R usually tells you what is wrongLisez le message : R dit généralement ce qui ne va pas

Method. (1) Read the first error message (the next ones are often consequences). (2) Look at the line it points to and the line just before. (3) Copy the message into a search engine: someone has had the same problem. (4) Restart R (Session → Restart R) and re-run the script from the top: many errors come from objects left in memory.

Méthode. (1) Lisez le premier message d’erreur (les suivants en sont souvent la conséquence). (2) Regardez la ligne indiquée et celle juste avant. (3) Copiez le message dans un moteur de recherche : quelqu’un a eu le même problème. (4) Redémarrez R (Session → Restart R) et relancez le script depuis le début : beaucoup d’erreurs viennent d’objets restés en mémoire.
