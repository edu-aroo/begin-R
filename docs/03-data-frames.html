3 · Data frames & importing data3 · Data frames et importation

~2.5 h

By the end of this session you will be able to

  • explain what a data frame is and how it relates to a field data sheet;
  • import a CSV file with read.csv();
  • explore a dataset with str(), head(), summary(), nrow(), names();
  • access columns with $, rows and cells with [row, column];
  • add a new column and save a table with write.csv().

À la fin de cette séance vous saurez

  • expliquer ce qu’est un data frame et son lien avec une fiche de terrain ;
  • importer un fichier CSV avec read.csv() ;
  • explorer un jeu de données avec str(), head(), summary(), nrow(), names() ;
  • accéder aux colonnes avec $, aux lignes et cellules avec [ligne, colonne] ;
  • ajouter une colonne et enregistrer un tableau avec write.csv().

The seagrass surveyLe suivi des herbiers

From now on we work with a (simulated) seagrass survey: 4 sites, two inside a Marine Protected Area (MPA) and two outside, with 15 quadrats of 50 × 50 cm per site. For each quadrat the team recorded the date, depth, dominant species, % seagrass cover, canopy height (cm) and shoot density (shoots per m²).

Désormais, nous travaillons sur un suivi (simulé) d’herbiers : 4 sites, deux à l’intérieur d’une Aire Marine Protégée (AMP) et deux à l’extérieur, avec 15 quadrats de 50 × 50 cm par site. Pour chaque quadrat l’équipe a noté la date, la profondeur, l’espèce dominante, le % de recouvrement, la hauteur de canopée (cm) et la densité de pousses (pousses par m²).

Seagrass survey (seagrass_quadrats.csv): in March 2026 a team of two snorkellers sampled 4 sites (Ambalaboy and Fasimena inside a Marine Protected Area, Belitsaky and Tsiandamba outside), 15 quadrats of 50 × 50 cm per site, placed every 5 m along a tape. For each quadrat they wrote on an underwater slate the depth (dive computer), the dominant species, the % cover (visual estimate), the canopy height (ruler, cm) and the number of shoots, converted to shoots per m². Type: one row = one quadrat; numeric (continuous) and categorical variables.

Suivi des herbiers (seagrass_quadrats.csv) : en mars 2026, une équipe de deux plongeurs en apnée a échantillonné 4 sites (Ambalaboy et Fasimena dans une Aire Marine Protégée, Belitsaky et Tsiandamba à l’extérieur), 15 quadrats de 50 × 50 cm par site, posés tous les 5 m le long d’un ruban. Pour chaque quadrat ils ont noté sur une ardoise la profondeur (ordinateur de plongée), l’espèce dominante, le % de recouvrement (estimation visuelle), la hauteur de canopée (règle, cm) et le nombre de pousses, converti en pousses par m². Type : une ligne = un quadrat ; variables numériques (continues) et catégorielles.

⇩ seagrass_quadrats.csv

What is a data frame?Qu’est-ce qu’un data frame ?

A data frame is a table: a set of vectors of the same length, placed side by side. Each column is a variable (and has one type); each row is an observation (here, one quadrat). It is exactly the structure of a well-organised field sheet or Excel table.

Un data frame est un tableau : un ensemble de vecteurs de même longueur, placés côte à côte. Chaque colonne est une variable (et a un seul type) ; chaque ligne est une observation (ici, un quadrat). C’est exactement la structure d’une fiche de terrain ou d’un tableau Excel bien organisé.

# a small data frame typed by hand
mini <- data.frame(
  site    = c("Ambalaboy", "Ambalaboy", "Tsiandamba"),
  quadrat = c(1, 2, 1),
  cover   = c(69, 47, 30)
)
mini
#>         site quadrat cover
#> 1  Ambalaboy       1    69
#> 2  Ambalaboy       2    47
#> 3 Tsiandamba       1    30

Here site = c(...) is not an argument of data.frame() with a fixed name: you choose the column names. Writing a long call over several lines, one argument per line, makes it easier to read; R waits for the closing ).

Ici site = c(...) n’est pas un argument de data.frame() au nom imposé : c’est vous qui choisissez les noms des colonnes. Écrire un appel long sur plusieurs lignes, un argument par ligne, le rend plus lisible ; R attend la ) finale.

Tidy data rule: one row = one observation, one column = one variable, one cell = one value. Avoid merged cells, colours used as information, or several values in one cell (e.g. “45% Thalassia”). Data organised this way can be read by R directly.

Règle des données « tidy » (bien rangées) : une ligne = une observation, une colonne = une variable, une cellule = une valeur. Évitez les cellules fusionnées, les couleurs utilisées comme information, ou plusieurs valeurs dans une cellule (ex. « 45% Thalassia »). Des données organisées ainsi se lisent directement dans R.

Importing a CSV fileImporter un fichier CSV

A CSV (comma-separated values) file is a plain text table: one line per row, values separated by commas. Any spreadsheet can save in CSV (File → Save as → CSV). Because your RStudio project is open, the path is simply relative to the project folder.

Un fichier CSV (comma-separated values) est un tableau en texte brut : une ligne par rangée, valeurs séparées par des virgules. Tout tableur peut enregistrer en CSV (Fichier → Enregistrer sous → CSV). Comme votre projet RStudio est ouvert, le chemin est simplement relatif au dossier du projet.

sg <- read.csv("data/seagrass_quadrats.csv")   # sg = seagrass

French-style CSV. If your Excel uses a comma as decimal separator, it saves CSV files with semicolons (;). Read them with read.csv2() instead (or read.csv(file, sep = ";", dec = ",")). If all your data end up in one single column, this is the reason.

“cannot open file … No such file or directory” means the path is wrong: check the spelling, the extension, and that the project is open.

CSV « à la française ». Si votre Excel utilise la virgule comme séparateur décimal, il enregistre les CSV avec des points-virgules (;). Lisez-les alors avec read.csv2() (ou read.csv(fichier, sep = ";", dec = ",")). Si toutes vos données se retrouvent dans une seule colonne, c’est la raison.

« cannot open file … No such file or directory » signifie que le chemin est faux : vérifiez l’orthographe, l’extension, et que le projet est ouvert.

Accessing columns, rows and cellsAccéder aux colonnes, lignes et cellules

The $ sign extracts one column as a vector. RStudio proposes the column names after you type sg$ (press Tab).

Le signe $ extrait une colonne sous forme de vecteur. RStudio propose les noms de colonnes après avoir tapé sg$ (appuyez sur Tab).

Square brackets on a data frame take two positions: [rows, columns]. Leave one empty to mean “all”.

Les crochets sur un data frame prennent deux positions : [lignes, colonnes]. Laisser vide signifie « tout ».

Adding a column and savingAjouter une colonne et enregistrer

Assigning to a column name that does not exist yet creates it. Here we add the cover as a proportion and the number of shoots actually counted in the 0.25 m² quadrat.

Affecter une valeur à un nom de colonne qui n’existe pas encore la crée. Ici nous ajoutons le recouvrement en proportion et le nombre de pousses réellement comptées dans le quadrat de 0,25 m².

sg$cover_prop    <- sg$seagrass_cover / 100
sg$shoots_counted <- sg$shoot_density * 0.25
head(sg[, c("site", "seagrass_cover", "cover_prop", "shoot_density", "shoots_counted")], 3)
#>        site seagrass_cover cover_prop shoot_density shoots_counted
#> 1 Ambalaboy             69       0.69           648            162
#> 2 Ambalaboy             47       0.47           464            116
#> 3 Ambalaboy             64       0.64           504            126
write.csv(sg, "outputs/seagrass_with_new_columns.csv", row.names = FALSE)
# row.names = FALSE avoids an extra unnamed column of row numbers
