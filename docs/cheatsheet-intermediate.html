I6 — FunctionsI6 — Fonctions

sgr <- function(w0, w1, days) {            # name <- function(arguments)
  if (any(w0 <= 0)) stop("weights must be positive")   # check the inputs
  100 * (log(w1) - log(w0)) / days         # the last value is returned
}
se <- function(x) sd(x, na.rm = TRUE) / sqrt(sum(!is.na(x)))
cv <- function(x) 100 * sd(x, na.rm = TRUE) / mean(x, na.rm = TRUE)
geo_mean <- function(x) exp(mean(log(x), na.rm = TRUE))
  • Write a function as soon as you copy-paste the same code three times. Test it on a case you can compute by hand.Écrivez une fonction dès que vous copiez-collez le même code trois fois. Testez-la sur un cas calculable à la main.
  • Arguments can have defaults: function(x, digits = 2). Use return() only to stop early; stop() / warning() for errors.Les arguments peuvent avoir des valeurs par défaut : function(x, digits = 2). return() seulement pour sortir plus tôt ; stop() / warning() pour les erreurs.

QuestionQuestion ParametricParamétrique Non-parametric / exactNon paramétrique / exact

  • Plot first. Choose the test from the question, the variable types and pairing, before looking at p.Tracez d’abord. Choisissez le test d’après la question, le type des variables et l’appariement, avant de regarder p.
  • chisq.test(t)$expected checks the counts; tt$estimate, tt$conf.int, tt$p.value extract results.chisq.test(t)$expected vérifie les effectifs ; tt$estimate, tt$conf.int, tt$p.value extraient les résultats.
  • Curved (rise then fall) relationship: no correlation coefficient fits — describe it with a graph.Relation courbe (monte puis descend) : aucun coefficient de corrélation ne convient — décrivez-la par un graphique.
