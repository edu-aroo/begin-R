I5 · Conditions and loopsI5 · Conditions et boucles

~2.5 h

By the end of this session you will be able to

  • run code only when a condition is true with if / else if / else;
  • classify a whole column with ifelse() and dplyr::case_when();
  • repeat a task with a for loop, store the results and avoid common mistakes;
  • know when a loop is not needed (vectorised code, tapply(), group_by()).

À la fin de cette séance vous saurez

  • exécuter du code seulement si une condition est vraie avec if / else if / else ;
  • classer une colonne entière avec ifelse() et dplyr::case_when() ;
  • répéter une tâche avec une boucle for, stocker les résultats et éviter les erreurs courantes ;
  • savoir quand une boucle n’est pas nécessaire (code vectorisé, tapply(), group_by()).

This session uses the analysis table of Session I3: seaweed <- read.csv("data/checkpoints/I3_seaweed_analysis.csv").

Cette séance utilise le tableau d’analyse de la séance I3 : seaweed <- read.csv("data/checkpoints/I3_seaweed_analysis.csv").

Why automate?Pourquoi automatiser ?

The cooperative wants, for each of the 12 villages, a short summary and a CSV file to send to the village representative. Copying the same 6 lines of code 12 times is slow and dangerous: one forgotten change and a village gets the wrong numbers. Conditions and loops let you write the logic once.

La coopérative veut, pour chacun des 12 villages, un petit résumé et un fichier CSV à envoyer au représentant du village. Copier les mêmes 6 lignes de code 12 fois est lent et dangereux : un changement oublié et un village reçoit de faux chiffres. Les conditions et les boucles permettent d’écrire la logique une seule fois.

if, else if, elseif, else if, else

if (condition) { ... } runs the block only if the condition is one TRUE. Add else if and else for the other cases.

if (condition) { ... } exécute le bloc seulement si la condition vaut un seul TRUE. Ajoutez else if et else pour les autres cas.

if needs a single TRUE/FALSE. if (seaweed$sgr > 4) is an error (“the condition has length > 1”), because there are 2 575 values. To classify a whole column, use ifelse() or case_when() (next section). Also, if (NA) is an error: test missing values first with is.na().

Pour classer une colonne entière, utilisez ifelse() ou case_when() (section suivante). De plus, if (NA) est une erreur : testez d’abord les valeurs manquantes avec is.na().

Classifying a column: ifelse() and case_when()Classer une colonne : ifelse() et case_when()

ifelse(test, yes, no) works on a whole vector. Nested ifelse() becomes hard to read beyond 2–3 classes: case_when() (dplyr) lists the cases one per line, condition ~ value, checked in order; TRUE ~ catches everything else.

ifelse(test, oui, non) fonctionne sur un vecteur entier. Les ifelse() imbriqués deviennent illisibles au-delà de 2–3 classes : case_when() (dplyr) liste les cas un par ligne, condition ~ valeur, testés dans l’ordre ; TRUE ~ attrape tout le reste.

ifelse()

seaweed$growth_class <- ifelse(is.na(seaweed$sgr), "lost",
                        ifelse(seaweed$sgr >= 4, "good",
                        ifelse(seaweed$sgr >= 3, "medium", "poor")))
table(seaweed$growth_class)
#> 
#>   good   lost medium   poor 
#>    473    258   1229    615

case_when()

library(dplyr)
seaweed <- seaweed %>% mutate(growth_class = case_when(
  is.na(sgr) ~ "lost",
  sgr >= 4   ~ "good",
  sgr >= 3   ~ "medium",
  TRUE       ~ "poor"))
table(seaweed$growth_class)
#> 
#>   good   lost medium   poor 
#>    473    258   1229    615

for (v in valeurs) { ... } exécute le bloc une fois pour chaque valeur, rangée dans v. Trois schémas couvrent la plupart des besoins.

2. Fill a vector of results2. Remplir un vecteur de résultats

Create an empty container before the loop, with the right length, then fill one element per turn. seq_along(x) gives 1, 2, …, length(x) — safer than 1:length(x) when x is empty.

loss <- numeric(length(villages))          # 12 zeros
names(loss) <- villages
for (i in seq_along(villages)) {

while and break (rarely needed)while et break (rarement utiles)

while (condition) { ... } repeats as long as the condition is true — for example until a target is reached. break leaves a loop early; next skips to the next turn. Always make sure the condition becomes FALSE, otherwise the loop never stops (press Esc in RStudio).

while (condition) { ... } répète tant que la condition est vraie — par exemple jusqu’à atteindre un objectif. break sort d’une boucle plus tôt ; next passe au tour suivant. Assurez-vous que la condition devient FALSE, sinon la boucle ne s’arrête jamais (appuyez sur Échap dans RStudio).

# How many days for 10 kg of cuttings to reach 30 kg at 3.5 % per day?
w <- 10; day <- 0
while (w < 30) { w <- w * exp(0.035); day <- day + 1 }
day
#> [1] 32

Application work I5

Script scripts/i05_loops.R, with the I3 analysis table.

  1. Create growth_class with case_when(): lost (no SGR), good (≥ 4), medium (≥ 3), poor (otherwise). How many good lines? How many poor?
  2. With a for loop over the villages, compute the % of lines not harvested (lost). Which village has the highest loss rate, and what is it (1 decimal)?
  3. With a loop, build the summary table (one row per village) including the total harvest in tonnes. Total harvest of Mahavelo (3 decimals)? Which village harvested the most?
  4. How many lines were lost in a storm in the South zone?
  5. With while: how many days for 12 kg of cuttings to exceed 50 kg at 4 % per day (w * exp(0.04) each day)?
  6. How many lines were planted in the wet season of 2024?
  7. Use the loop to write one CSV per village in outputs/villages/ (not graded, but useful for the practice session).

Script scripts/i05_loops.R, avec le tableau d’analyse I3.

  1. Créez growth_class avec case_when() : lost (pas de SGR), good (≥ 4), medium (≥ 3), poor (sinon). Combien de lignes good ? Combien de poor ?

library(dplyr)
seaweed <- read.csv("data/checkpoints/I3_seaweed_analysis.csv")
seaweed <- seaweed %>% mutate(growth_class = case_when(
  is.na(sgr) ~ "lost", sgr >= 4 ~ "good", sgr >= 3 ~ "medium", TRUE ~ "poor"))
table(seaweed$growth_class)                                       # 1

villages <- sort(unique(seaweed$village))
res <- vector("list", length(villages))
for (i in seq_along(villages)) {
  d <- seaweed[seaweed$village == villages[i], ]
  res[[i]] <- data.frame(village = villages[i],
                         loss_pct = 100 * mean(d$status != "harvested"),
                         harvest_t = sum(d$final_weight_kg, na.rm = TRUE) / 1000)
}
summary_v <- do.call(rbind, res)
summary_v[which.max(summary_v$loss_pct), ]                        # 2
summary_v[summary_v$village == "Mahavelo", ]                      # 3a
summary_v[which.max(summary_v$harvest_t), ]                       # 3b
sum(seaweed$zone == "South" & seaweed$status == "lost - storm")   # 4
w <- 12; day <- 0
while (w < 50) { w <- w * exp(0.04); day <- day + 1 }
day                                                               # 5
sum(seaweed$year == 2024 & seaweed$season == "wet")               # 6
